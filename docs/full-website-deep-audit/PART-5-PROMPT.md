# PART 5 — SCHEMA + CONTENT GAP + PRIORITY ROADMAP

## 5.1 STRUCTURED DATA / SCHEMA

Audit all applicable schema: Organization, LocalBusiness, Service, WebSite,
BreadcrumbList, FAQPage, Article, BlogPosting, Person, Review,
AggregateRating, ImageObject, PostalAddress. Determine missing schema, invalid
schema, duplicate schema, contradictory schema, incorrect schema, schema/content
mismatch, unnecessary schema. IMPORTANT: Do not recommend schema simply for the
sake of adding schema. Schema must represent visible, accurate page content.

## 5.2 BREADCRUMBS

Audit implementation, hierarchy, consistency, schema, usability.

## 5.3 IMAGE SEO

Audit alt text, filenames, image relevance, image compression, dimensions, lazy
loading, WebP/AVIF, duplicate images, stock images, real project images, image
context. Identify opportunities for unique project photography.

## 5.4 CONTENT GAP ANALYSIS

Identify topics competitors cover that KL Servis Rumah does not. Classify gaps
as High / Medium / Low priority. For each gap provide topic, intent, suggested
URL, primary keyword/theme, supporting entities, suggested headings, internal
links, conversion opportunity, AI-answer opportunity.

## 5.5 KEYWORD CANNIBALIZATION

Find pages targeting the same keyword, topic, service, location, or intent.
Identify competing pages. For each conflict recommend keep, merge, redirect,
re-target, change intent, change title, change content, change internal links.

## 5.6 CONTENT DECAY

Identify pages that may have old information, outdated pricing, outdated service
descriptions, old locations, outdated claims, weak CTR, falling traffic, falling
rankings. Recommend refresh strategy.

## 5.7 BRAND / ENTITY CONTENT

Audit About, Contact, Services, Service areas, Team, Projects, Reviews, FAQ,
Policies. Determine whether these pages create enough trust for both users and
search/AI systems.
