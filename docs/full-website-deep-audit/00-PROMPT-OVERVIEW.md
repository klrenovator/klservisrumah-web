## AUDIT PHILOSOPHY

Do not focus only on traditional Google rankings. The website must be evaluated
for visibility and usefulness across Google Search, Google AI Overviews, Google
AI Mode, Bing, Bing Copilot, ChatGPT, Perplexity, Gemini, Claude, and other
LLM-based search/discovery systems. Evaluate the website for SEO, Technical SEO,
On-page SEO, Semantic SEO, Entity SEO, Local SEO, AEO, GEO, LLMO, AIO / AI SEO,
SXO, CRO, Information Architecture, Internal Linking, Topical Authority,
Content Quality, E-E-A-T, Structured Data, Indexation, Crawlability, Rendering,
Performance, UX, Conversion, Trust, Brand signals, and AI citation potential.

## DO NOT MAKE ASSUMPTIONS

Do not assume that every indexed page is useful, every sitemap URL should be
indexed, more pages = more SEO, programmatic pages are automatically good,
location pages are automatically valuable, keyword variations require separate
pages, schema automatically improves rankings, AI-generated content is
acceptable, high word count means high quality, keyword density is important,
every page needs to rank, canonical tags are correct simply because they exist,
robots.txt is correct simply because it exists, or sitemap is correct simply
because Google accepts it. **Challenge the website architecture itself.**

## FINAL OUTPUT REQUIREMENTS

DO NOT give a generic summary. Produce a professional enterprise-level audit.
The final audit must contain:

- **A. EXECUTIVE SUMMARY** — Overall + per-discipline scores out of 100.
- **B. CRITICAL ISSUES** — Problem / Evidence / Affected pages / Why it matters /
  Severity / Recommended solution / Implementation difficulty / Expected impact.
- **C. QUICK WINS** — Easy, meaningful, immediate changes.
- **D. BIG PROJECTS** — Changes requiring dev / SEO / content / design / marketing.
- **E. 5,000+ PAGE ACTION MATRIX** — KEEP / IMPROVE / MERGE / REDIRECT / NOINDEX /
  DELETE / CANONICALIZE / REWRITE / RESTRUCTURE by URL pattern & template.
- **F. PAGE TEMPLATE AUDIT** — Homepage, service hub, service page, location page,
  service+location page, problem page, blog, FAQ, about, contact, project/case
  study, commercial landing.
- **G. INTERNAL LINKING BLUEPRINT** — Pillar / cluster / supporting / location /
  problem / commercial link architecture.
- **H. TOPICAL AUTHORITY MAP** — Pillar / cluster / subcluster / supporting /
  FAQ / problem / commercial; identify missing topics.
- **I. AI SEARCH STRATEGY** — Per engine (Google AI Overviews, AI Mode, ChatGPT,
  Perplexity, Gemini, Bing/Copilot) for discovery / retrieval / mention /
  summarization / citation / recommendation; prioritised by impact, effort, risk,
  dependencies.
- **J. PRIORITY SCORE** — Every recommendation: SEO Impact /10, Business Impact /10,
  AI Visibility Impact /10, Difficulty /10, Priority P0–P3.
- **K. DEVELOPER TASK LIST** — Task / Reason / Affected system / Expected result /
  Acceptance criteria.
- **L. CONTENT TEAM TASK LIST** — Rewrite / merge / expand / new / FAQs / case
  studies / location content / problem-solution content / entity content.
- **M. SEO TEAM TASK LIST** — Technical / on-page / internal linking / schema /
  indexation / content / local SEO / entity SEO / AI SEO.
- **N. FINAL "WHAT IS WRONG WITH THIS WEBSITE?"** — 20 biggest weaknesses,
  20 biggest opportunities, and "if we fix only 10 things, what first?"

## FINAL RULE

Do not try to make KL Servis Rumah look good. The objective is to FIND PROBLEMS.
Be critical, specific, evidence-based. For every recommendation explain WHAT is
wrong, WHY it is wrong, WHERE it is happening, HOW to fix it, WHO should fix it,
