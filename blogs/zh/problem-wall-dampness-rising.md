# 墙脚返潮：为什么墙面下半截总是起皮脱漆

**问题：** 为什么我家墙面只有靠近地面的那半米一直起泡、脱皮，还泛出白色粉末，不管重刷几次都一样？

**回答：** 这种形态叫毛细返潮（rising damp）。地面或墙体背后湿区的水分，通过多孔的砖体与抹灰以毛细作用向上爬升，并把溶解的盐分一起带上来。水在墙表面蒸发后，盐分结晶——就是那层白色粉末，称为泛碱（efflorescence）——晶体生长的推力把漆膜从墙上顶开。重新刷漆之所以无效，是因为水分与含盐的抹灰层都还在。正确顺序是：找出并切断水源、铲除受污染抹灰、施作防潮体系，再重新抹灰并用相容的涂料饰面。

在吉隆坡与雪兰莪，墙脚返潮常见于屋龄较长的有地住宅、底层单位，以及背靠浴室、花槽、明沟或硬化铺装的墙体。

## 返潮的典型特征

| 现象 | 说明 |
|---|---|
| 损坏只集中在墙脚 300–1,000 mm，上缘大致平齐 | 典型返潮 — 水上升到蒸发与补给达到平衡的高度 |
| 白色粉状或结晶状析出物 | 泛碱 — 水蒸发后留下的盐分 |
| 漆膜成片鼓起脱落，而非随机剥落 | 盐结晶把漆膜顶开 |
| 抹灰发软、发砂、敲击空鼓 | 含盐且已劣化的抹灰层 |
| 踢脚线附近有霉味 | 墙脚长期含水 |
| 木踢脚线膨胀或腐烂 | 地面标高处长期受潮 |

如果损坏位置偏高、呈块状分布，或从天花往下蔓延，那就不是返潮 — 请参见[墙面受潮与油漆起泡](/zh/problems/damp-walls-paint-bubbling)。

## 四个真实来源

### 1. 地下水汽穿过砖体
砖、砌块与水泥砂浆都是多孔材料。当防潮层（DPC）缺失、破损或被跨越时，地下水就会沿毛细通道爬进墙体。这是教科书式的机理，在老旧有地住宅中最常见。

### 2. 室外地坪或铺装高过防潮层
混凝土车道、露台、花槽与后加的铺装，经常做得比原始地坪更高，于是雨水贴着墙体停留在防潮层以上，直接从屏障上方进入砖体。这是最常见、也最容易根治的原因之一。

### 3. 墙体背后有渗漏
暗管缓慢渗漏、隔壁就是浴室、或淋浴墙防水失效，都会在墙脚造成看起来和返潮一模一样的潮湿。必须先排除，因为处理方式完全不同。

### 4. 墙边排水不良
周边明沟堵塞、落水管直接冲在墙脚、地面坡向朝房子，都会让砖体长期饱水。在马来西亚的降雨量下，光是这一点就足以维持一条永久的潮湿带。

## 为什么只刷防水漆一定失败

很多屋主会在受影响区域刷一层「防潮」或防水涂料，失败的原因有两个：

1. **盐分还留在抹灰层里。** 吸湿性盐分会从空气中吸水，即使原始水源已切断，抹灰仍然保持潮湿，结晶会在新涂层底下继续发生。
2. **封住一面只是让水改道。** 成膜涂料阻断了该处的蒸发，水便向上爬得更高或往两侧移动，损坏会出现在处理带的上方或旁边，往往比原来更严重。

含盐抹灰必须铲除，不能覆盖。

## 正确的施工顺序

1. **先诊断来源。** 判定水分来自地下、室外地坪，还是墙后渗漏。在不同高度取湿度读数可看出形态；水管检查则可排除暗管问题。
2. **切断来源。** 降低室外铺装标高或做排水沟导流、改接落水管、清通周边明沟，或修复渗漏。跳过这一步，复发是必然的。
3. **铲除受污染抹灰。** 沿可见潮湿最高线往上约 300–500 mm 全部铲到坚实砖面。
4. **让墙体干燥。** 干燥需要时间——依墙厚与天气常需数周。这是最常被赶工省略的一步。
5. **施作防潮体系。** 依墙体构造与诊断结果，选用抗盐砂浆或合适的防潮系统。
6. **重新抹灰与饰面。** 批灰找平后上抗碱封闭底漆，再用透气、可擦洗的面漆。仍需呼吸的墙体不要用不透气涂层。

## 屋主最常犯的错

- **马上重新刷漆。** 最常见也最费钱的做法——新漆几个月内就会再失败。
- **磨掉白霜再刷封闭漆。** 去掉看得见的盐，对留在抹灰里的盐毫无作用。
- **把所有墙脚潮湿都当成返潮。** 暗管渗漏是很常见的另一种可能，需要的是[水管漏水检测](/zh/services/plumbing/water-leakage-diagnosis-and-repair)，而不是防水工程。
- **墙没干就做饰面。** 被闷住的水分会像当初一样，把新饰面再顶开一次。

## 常见问题

### 返潮到底是什么？
水分通过多孔墙体材料以毛细作用向上移动，来自地面或相邻湿区，并把溶解的盐分带到表面结晶。

### 马来西亚会有返潮吗？
墙脚受潮在本地非常普遍，成因包括高降雨量、地下水汽充足、铺装做得高过防潮层，以及周边排水不良。某个案例究竟是真正的地下返潮还是渗漏，需要现场确认。

### 用防水漆能解决返潮吗？
不能。在含盐抹灰上覆盖涂层，只会把水分闷住，并让损坏往墙面更高处转移。

### 多久之后才能重新刷漆？
必须在切断水源、铲除抹灰之后，让墙体真正干燥，通常需要数周。提前上漆，正是许多工程二次失败的原因。

### 返潮算结构问题吗？
它主要是耐久性与饰面问题，但长期受潮会劣化抹灰、腐蚀木踢脚与门框、并助长霉菌，所以值得认真处理。

### 怎么和漏水区分？
返潮的上缘大致平齐，且只限于墙脚。漏水则是从某一点向外扩散的斑块，位置往往更高，而且可能在使用某个洁具时明显加重。
