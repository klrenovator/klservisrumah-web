# 深度清洁后砖缝仍有污渍怎么办

**问题：** 我花钱做了专业深度清洁，但卫生间和厨房的砖缝还是又黑又脏。还有什么办法能弄干净吗？

**回答：** 有——但方法取决于砖缝为什么脏。砖缝是多孔的，有些污渍会渗进深处。深层的霉菌和矿物质沉积、硬水渍、或之前封层做得差，都说明变色发生在砖缝内部而非表面，所以再怎么刷洗表面也刷不掉。两个可靠的办法是：用蒸汽和砖缝清洁剂做专业清洁，再涂渗透型密封剂；或者当砖缝严重老化时，重新填缝或做彩色封缝。两者都能恢复干净均匀的外观，怎么选取决于损伤有多深。

## 砖缝为什么会一直脏

| 原因 | 外观 |
|---|---|
| 深层霉菌 | 淋浴与洗手盆区发黑发绿 |
| 硬水矿物质沉积 | 白垩状白色或灰色沉积 |
| 砖缝老旧多孔 | 污渍渗进去，从没彻底清掉 |
| 旧封层失效 | 清洁后很快又脏 |
| 厨房油垢渗入 | 灶台附近油污发黑的缝 |

## 清洁 vs 重填缝 vs 彩色封缝

| 方法 | 适用情况 | 效果 |
|---|---|---|
| 深度清洁 + 蒸汽 + 密封 | 表面及中度污渍 | 恢复砖缝原色 |
| 彩色封缝 | 均匀发黑、砖缝完整 | 均匀的新颜色并密封 |
| 重新填缝 | 砖缝开裂、酥脆或严重污渍 | 全新的砖缝 |
| 组合处理 | 同一卫生间损伤不一 | 按需清洁、重封、重填 |

对结构仍完好的砖缝，[瓷砖维修与重新填缝](/zh/services/tiling/tile-repair-and-re-grouting)往往是最快达到均匀外观的途径。对开裂或酥脆的砖缝，铲除重填是唯一持久的办法——参见[瓷砖缝开裂](/zh/problems/cracked-tile-grout)。

## 每种做法包括什么

### 深度清洁 + 密封
用砖缝专用清洁剂和蒸汽去除表面污渍，再涂渗透型密封剂，让日后的污渍停留在表面、一擦就掉。

### 彩色封缝
清洁砖缝后，把带色密封剂刷在缝上，等它固化。这一步同时完成着色和密封，正常使用下通常能维持两到四年。

### 重新填缝
把旧填缝料抠掉，清理接缝，再填上新料并收边。砖缝开裂或脱落时这是正确的修法，因为密封剂补不了失效的接缝。

## 常见问题

### 不重新填缝也能恢复砖缝颜色吗？
往往可以。砖缝仍完整时，专业清洁加彩色封缝就能恢复均匀颜色。只有开裂或酥脆的砖缝才需要重新填缝。

### 彩色封缝能维持多久？
通常两到四年，视使用频率和所用清洁产品而定。

### 为什么深度清洁后砖缝又脏了？
砖缝多半多孔且没密封，污渍又渗了进去。清洁后涂渗透型密封剂，才能防止快速变脏。

### 重新填缝是大工程吗？
单个卫生间通常是包含铲除、重填、固化在内的一到两天工程。新料固化期间区域要保干。

### 能只用漂白水刷砖缝吗？
漂白水能提亮表面霉斑，但去不掉矿物质沉积，也不会重新密封砖缝，用得重还会削弱接缝。专业清洁加密封持久得多。
