# 吉隆坡公寓退房深度清洁：交楼清单

**问题：**公寓退房深度清洁包括什么？

**答案：**合格的退房清洁应覆盖浴室、厨房、入墙柜、窗户、地板、墙壁、开关和电器，让单位准备好房东或管理处验房。它比每周清洁更细，因为要清除油垢、水垢、填缝发黑、柜内灰尘和搬屋留下的污渍。

本文讲**退房/交楼清洁**。新装修单位请参考[装修后水泥渍与粉尘清洁](/zh/problems/cement-splatter-tile-clean)和[装修后清洁](/zh/services/post-renovation-cleaning)。

## 房东通常检查什么

| 区域 | 检查内容 |
|---|---|
| 浴室 | 水垢、霉菌、填缝、马桶、淋浴玻璃 |
| 厨房 | 橱柜、灶台、抽油烟机、水槽和瓷砖油垢 |
| 入墙柜 | 层板、轨道和抽屉内灰尘 |
| 地板 | 污渍、黏腻点、残留胶带和痕迹 |
| 窗户 | 玻璃、轨道、窗台和框 |
| 墙面 | 擦痕、钉孔、重污渍 |
| 电器 | 冰箱、洗衣机、风扇和滤网（如包含） |

## 退房清洁范围

深度清洁应包括：

1. **厨房：**为橱柜、灶台、抽油烟机、瓷砖墙面、水槽和水龙头除油。
2. **浴室：**为淋浴玻璃、水龙头、马桶、地面和填缝除垢。
3. **橱柜：**擦拭衣柜、厨柜和抽屉内外。
4. **窗户：**清洁玻璃、轨道、窗台和可触及框架。
5. **地板：**吸尘、拖地并清除黏腻残留。
6. **墙面和开关：**擦拭开关、门把手和可触及擦痕。
7. **设备：**清洁可触及的风扇叶、冷气外壳和灯具。

## 哪些可能需要另外处理

退房清洁不等于维修。以下项目可能需要另行报价：

- 涂刷擦痕、钉孔或墙面损坏。
- 修补裂砖、空鼓砖或填缝。
- 清除装修后水泥渍和油漆。
- 清运大件垃圾或不要的家具。
- 清洁安全范围外的外窗。
- 处理正在漏水导致的霉菌。

如果交楼前刚装修，应先预约[装修后清洁](/zh/services/post-renovation-cleaning)，因为水泥灰、硅胶残留和保护膜需要不同流程。

## 时间安排

800–1,200 平方英尺的公寓，一位清洁员通常需要数小时，团队会更快。带家具、厨房重油污和多浴室会增加时间。建议在最终验房前预约，留出补清时间。

## 常见问题

### 退房清洁和定期清洁一样吗？
不一样。退房清洁更细，针对油垢、水垢、柜内、窗户、轨道和交楼表面。

### 清洁能去掉墙面擦痕吗？
轻微痕迹可能擦掉；深度擦痕、钉孔和油漆损坏通常需要修补和刷漆，不是清洁能解决。
