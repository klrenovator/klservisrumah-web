# 浴室漏水：楼下地板潮湿与墙面受潮

**问题：** 楼上浴室下面的地板潮湿，或浴室旁的墙出现棕色渍和油漆起泡。一定要砸砖吗？

**回答：** 通常不必。浴室漏水不外乎四种：地面防水膜开裂、淋浴屏或浴缸周围硅胶失效、墙内暗管漏水，或砖缝 grout 破损让水进入楼板。打压测试可以分开水管漏和楼板漏。多数情况下可以从下方用高压 PU 灌浆封楼板——不伤瓷砖。只有防水膜全面失效，才需要砸砖重做防水。

本页是浴室往结构里漏的**源头诊断**。楼下天花视角以及 PU 对比全面砸砖的详细选择，见[楼上浴室漏水](/zh/problems/bathroom-leak-upper-floor)。如果只是淋浴玻璃往浴室地板滴，见[淋浴屏漏水](/zh/problems/shower-screen-leaking)。

## 水怎样离开马来西亚的浴室

- **地面防水膜开裂** — 砖下那层隐蔽卷材老化或被刺穿。
- **硅胶失效** 在淋浴屏、浴缸或墙地交接。
- **湿墙里的暗管**（给水或排水）漏水。
- **砖缝张开** 让淋浴水进入找平层和楼板。

楼下天花正在滴水属于高紧急。已公布的巴生谷活跃漏水指引是当天上门，通常 45 到 90 分钟到达。

## 水管漏还是楼板漏？

| 迹象 | 更可能 |
|---|---|
| 没人用浴室也在滴 | 给水暗管 |
| 只在淋浴中或淋浴后滴 | 防水膜、砖缝或硅胶 |
| 浴室旁墙起泡、楼下地板是干的 | 湿墙水管或溅水 |
| 淋浴盘正下方棕色渍 | 防水膜或盘边密封 |
| 湿斑一周比一周大 | 活跃漏水——不要等 |

## 可以立刻做的

1. 楼下天花在滴就先停用楼上花洒。
2. 每天同一时间拍湿斑，看是否在扩大。
3. 检查淋浴屏和浴缸硅胶有没有缺口或发霉失效。
4. 不要反复重刷楼下天花——水还在来。

如果多个卫生洁具同时有问题或有下水道气味，也要看[排水堵塞](/zh/problems/clogged-drain)。

## 诊断与维修包括什么

1. **水管打压**，分开管漏和板漏。
2. **从下方对楼板做 PU 灌浆**，漏点是发丝缝或局部膜破时。
3. **重打硅胶**，如果那是唯一通路。
4. **砸砖重做防水膜**，仅在湿区防水膜全面失效时。

防水工程适用公布的最长 5 年书面不漏保证。水管接口适用 30 天接口密封与工艺保修。
