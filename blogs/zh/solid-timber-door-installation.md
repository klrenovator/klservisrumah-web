# 吉隆坡与雪兰莪实木门安装

实木门是一整扇有分量的门扇——马来西亚家里常见柳安或成格——挂在正规门框上，用三只不锈钢铰链。手感与空心或防火板卧室门不同：更重、隔音更好，表面以后还能打磨翻新。

**直接回答：** KL Servis Rumah 供应并安装柳安或成格实木门，从 **RM 550** 起，需要时含柳安门框、三只 SS304 铰链、套线与基础执手锁。

想要能用很多年的大门手感，选这个。空调公寓卧室若要更轻、尺寸更稳定，选 [防火板门](/zh/services/door/laminate-door-installation)。

## 套餐包含什么

- 柳安或成格实木门扇（材种在报价上确认）。
- 现有门框不能再利用时的柳安门框。
- 三只 SS304 铰链 — 不锈钢，潮湿洞口不用未处理碳钢。
- 新门框的套线。
- 基础执手锁及钥匙。

玻璃视窗、雕花、高端拉手和 [智能锁](/zh/services/locksmith/smart-lock-installation) 另计。

## 柳安还是成格

| | 柳安 | 成格 |
|---|---|---|
| 常见用途 | 室内及许多住宅大门 | 更重、更耐用的近室外门 |
| 重量 | 重，好加工 | 更重 |
| 预期 | 六个面都要封闭 | 仍要封闭；不是“免维护” |

## 湿度、缝隙与油漆

实木会动。在巴生谷意味着：

- **六个面**都要做饰面（包括上下端头）。
- 在完成地面上留出计划净空。太紧，下雨后就会刮。见 [门刮地板](/zh/problems/door-scraping-floor)。
- 不要把未封闭的室内门扇挂进潮湿卫生间。

只因为铰链下垂才刮地，是铰链活，不是扔掉门的理由。见 [门铰链松动](/zh/problems/loose-door-hinge) 与 [铰链锁具维修](/zh/services/handyman/door-hinge-and-lockset-repair)。

## 留现有门框

门框牢固、方正、企口匹配，我们就在上面挂新实木门扇。仍会检查铰链螺丝握钉、缝隙是否均匀、锁舌企口是否对齐。

防火洞口不同：不能把装饰实木扇装到防火框上还声称有防火等级。那是 [防火门](/zh/services/door) 项目。

## 我们怎么挂实木门

1. 测量企口和完成地面高度。
2. 确认开启方向、锁高、门框是否保留。
3. 装铰链（整扇三只），悬挂，刨会合边使缝均匀。
4. 开锁体槽，装锁与锁扣板。
5. 新框则装套线；封闭端头。
6. 与您一起试开关。

## 常见问题

### 旧实木门能翻新而不换吗？

有时可以。门扇平整、边挺没裂、腐朽局部，打磨重封更便宜。已经弯成香蕉形的应更换。

### 以后能加智能锁吗？

可以，只要边挺够厚。开锁体前告诉我们锁型号。见 [智能锁安装](/zh/services/locksmith/smart-lock-installation)。

### 安装要多久？

旧框上换一扇门，门到场后常常当次完成。
