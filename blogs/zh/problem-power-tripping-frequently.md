# 家里电力频繁跳闸

**问题：** 总开关或漏电保护一天跳好几次，常常是某个电器一开就跳。是配电箱坏了，还是屋里有东西在漏电？

**回答：** 频繁跳闸通常是电器故障、回路过载、插座或天花进水，或旧配电箱断路器无力。漏电保护是在保护你——绝不要短接。先隔离回路、逐个试电器，再重新分配负荷或更换故障断路器。有烧焦味、一复位立刻再跳、或只在雨后跳，需要 ST 注册电工当天上门。

本页讲的是**整屋或回路跳闸**（过载、短路、断路器无力）。没有明显电器却跳的剩余电流装置，更详细见[RCCB 频繁跳闸](/zh/problems/rccb-tripping-kl)。

## 巴生谷住宅常见原因

- 故障电器过流或短路。
- 同一回路上大功率电器太多。
- 雨后插座或天花进水。
- 旧配电箱断路器无力。

## 怎么读跳闸

| 规律 | 可能原因 |
|---|---|
| 某个电器一开就跳 | 那个电器或其专用回路 |
| 好几样一起开才跳 | 过载——重新分配 |
| 几秒内立刻再跳 | 正在短路或漏电——不要再复位 |
| 只在雨后 | 灯具或天花进水 |
| 插座或配电箱有烧焦味 | 断电并打电话 |

## 可以安全做的

1. 记下跳的是哪一路、当时开了什么。
2. 拔掉最后那个电器，复位一次。
3. 立刻再跳就不要反复复位。
4. 不要用普通断路器替换漏电保护。

## 诊断包括什么

1. 逐路隔离找源头。
2. 逐个测试电器。
3. 把大功率电器分到不同回路。
4. 更换故障断路器或升级配电箱。配电箱可以一天升级完，不必整屋重布线。

电气工程适用 12 个月电气工艺保修，由 ST 注册电工施工。
