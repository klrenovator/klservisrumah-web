# 马桶冲水不畅：冲力弱或水箱不停流水

**问题：** 马桶冲力弱，按一次冲不干净，或冲完后一直流水。是修水箱，还是换整套？

**回答：** 冲力弱或水箱停不住，几乎总是挡板或冲水机构磨损、沿圈喷孔结垢、S 弯半堵，或进水阀故障。换挡板或进水阀是短工——公布指引含配件 **RM 150 至 RM 250**。陶瓷开裂，或过去两年反复换零件，就该换整套。

这是**水箱和冲水表现**问题。如果碗里水位上涨下不去，那是堵塞——见[马桶堵塞](/zh/problems/blocked-drain-toilet)。如果其他洁具也慢，见[排水堵塞](/zh/problems/clogged-drain)。

## 马来西亚住宅马桶为什么冲不好

- **挡板或双冲阀芯磨损** — 水箱存不住水，冲水量下降，水箱不停补水。
- **沿圈喷孔堵塞** — 硬水和水垢堵住圈下小孔，水不能从四周洗刷碗壁。
- **S 弯或排污管半堵** — 水出去了看起来像冲了，带不走固体。
- **进水阀（浮球）故障** — 水箱溢进溢流管，或永远到不了正确水位。

## 冲力弱还是不停流水

| 症状 | 常见部件 |
|---|---|
| 按一次冲不干净，水箱摸起来轻 | 水箱水位低 / 挡板在漏 |
| 两次冲水之间碗里有细流 | 挡板或冲水阀密封 |
| 沿圈四周冲刷都弱 | 喷孔结垢 |
| 要冲两三次，其他排水正常 | S 弯半堵 |
| 水箱一直嘶嘶响 | 进水阀 |

## 可以自查的

1. 打开水箱盖看一次冲水。按之前水位就低，说明挡板在漏。
2. 冲完后听。持续嘶声是进水阀。
3. 喷孔明显结垢时，用蘸醋的布擦——不要把浓酸倒进水箱。
4. 碗里水位已经很高就不要再冲——那是堵，不是机构弱。

## 专业维修包括什么

1. 更换挡板、进水阀或双冲阀芯。
2. 清除喷孔水垢。
3. 冲水量正常但碗仍冲不干净时，疏通 S 弯和排污管。
4. 老套件装整套水箱配件，陶瓷开裂则换整套马桶。
