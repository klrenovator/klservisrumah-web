# 无框淋浴屏底部漏水怎么办

**问题：** 每次洗澡，水都会从无框淋浴屏下面漏到卫生间地板上。能修吗，还是得换新的淋浴屏？

**回答：** 无框淋浴屏底部漏水几乎总能修好，而且很少是玻璃的问题。水跑出来的原因不外乎三种：底部的软质挡水条磨损或缺失、地面坡度没有把水导回淋浴区、或接缝处的硅胶失效。解决办法是更换底部封条、重新打接缝硅胶、检查坡度——只有玻璃开裂或边框严重锈蚀时，换新才是正确选择。

## 淋浴屏为什么在底部漏水

### 1. 底部封条磨损
底边那条透明或磁吸挡水条贴着地面弯折，用几年就会磨损。一旦硬化、开裂或脱落，水就直接从下面流出去。

### 2. 地面坡度不对
淋浴地面应当向地漏轻微倾斜。如果坡度做错或地面沉降，水会积在屏边附近并往外渗。

### 3. 边框或面板不平
如果淋浴屏装得略不平，底部封条就没法均匀贴地，在一端留出缝隙。

### 4. 硅胶失效
墙面接缝和地面交接处的硅胶会随时间老化、脱开，让水从边缘渗出去，而不是从门下流走。

## 读懂症状

| 症状 | 最可能原因 |
|---|---|
| 水从玻璃下某一点流出 | 底部封条磨损或开裂 |
| 墙脚处漏水 | 硅胶接缝失效 |
| 水积在屏外 | 地面坡度把水导出去 |
| 封条看着完好却还漏水 | 面板不平，或封条硬化 |
| 漏水越来越严重 | 封条与硅胶共同老化 |

## 正规维修包括什么

1. **检查底部封条**，换成正确的挡水或磁吸型材。
2. **检查面板是否水平**，若已下沉则调整铰链或支架。
3. **用合适的卫浴硅胶重新打接缝**，使用前让其充分固化。
4. **检查地面坡度**——坡度有问题时，可用门槛条把水导回淋浴区。
5. **只有玻璃开裂、或边框锈蚀到无法干净修复时，才换玻璃**。

## 常见问题

### 你们能只换封条吗？
能。大多数底部漏水，换个底部挡水或磁吸封条、重新打好接缝胶就能解决。

### 你们安装无框淋浴屏吗？
装。我们供货并安装钢化玻璃无框淋浴屏，公布价格由 RM 420 每扇起。

### 怎么判断是封条还是坡度的问题？
在底部倒一点水，看它往哪流。如果从玻璃下某一点直接流出去，通常是封条；如果积在屏外又流回来，就是坡度问题。

### 我能自己重新打胶吗？
小范围补胶可以自己动手，但整体重新打胶需要干净、干燥的表面和充分的固化时间才能持久——这正是专业做法的差别所在。

### 什么时候该整扇换掉？
玻璃开裂、边框锈蚀，或铰链明显松动时，换新比反复修更安全。
