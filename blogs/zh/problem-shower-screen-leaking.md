# 淋浴屏漏水到地面：原因与维修

**问题：**为什么水会从淋浴屏跑到浴室地面？

**答案：**淋浴屏漏水最常见的原因是玻璃胶失效、玻璃或框架错位、下轨堵塞、底部防水胶条老化，或安装时没有足够坡度流向地漏。重新打胶通常足够；持续漏水可能需要调整、修轨道或检查防水。

本文讲**淋浴屏漏水**，不是一般的[浴室漏水](/zh/problems/leaking-bathroom)（例如下楼天花板渗水）。如果楼下单位潮湿，应先按楼板或防水层问题处理。

## 常见原因

| 原因 | 可见现象 | 常见处理 |
|---|---|---|
| 玻璃胶老旧/发霉 | 水沿墙地接缝渗出 | 铲除后重新打胶 |
| 底部门挡胶条老化 | 水从门底流出 | 更换防水胶条 |
| 轨道排水孔堵塞 | 水从轨道溢出 | 清洁轨道和排水孔 |
| 门/玻璃错位 | 关门后出现缝隙 | 调整滑轮/铰链 |
| 地面无坡向地漏 | 水积水不流走 | 修正地面/瓷砖坡度 |
| 防水层失效 | 水到楼下天花板 | 防水检查 |

## 玻璃胶失效
淋浴屏周围的玻璃胶每天随浴室冷热变化而伸缩。多年后可能剥落、开裂或发黑发霉。密封不良会让水沿玻璃边缘进入墙地接缝。正确补胶要先割除旧胶、清洁霉菌、干燥接缝，再使用浴室级中性固化硅胶。

## 底部胶条和轨道
有框推拉屏依赖下轨和排水孔。皂垢和头发会堵住孔，导致轨道积水溢出。无框铰链屏依赖门底橡胶或乙烯基挡水条；胶条硬化或撕裂时，水会从下方流出。

## 错位和安装
门下沉会在底部留下缝隙。铰链屏可能需要调铰链；推拉屏可能需要调滑轮。如果屏幕装在接近平坦、没有坡度的区域，即使密封良好也会跑水。

## 会不会是防水问题？
淋浴时浴室地面积水通常是屏幕问题；但**楼下天花板**有水就不同，可能是防水层开裂、填缝失效、水管漏水或楼板裂缝。若水到楼下，请阅读[公寓阳台漏水](/zh/problems/balcony-leak-condo)和[混凝土楼板裂缝漏水](/zh/problems/concrete-slab-crack-leak)。

## 专业维修包含什么

1. 开水时找出确切漏水路径。
2. 清洁玻璃、框架、轨道和排水孔。
3. 更换损坏挡水条或垫片。
4. 调整铰链或滑轮，让门方正关闭。
5. 铲除旧胶并正确重新打胶。
6. 开水测试数分钟。

以下情况应联系：

## 常见问题

### 可以直接在旧玻璃胶上打新胶吗？
不建议。旧胶必须铲除，接缝要清洁干燥；新胶无法良好附着在受污染旧胶上。

### 浴室玻璃胶一般能用多久？
良好施工通常可使用数年，但强酸碱清洁剂、霉菌和伸缩运动会缩短寿命。

### 淋浴屏漏水一定是屏幕问题吗？
不一定。如果水出现在浴室下方，防水层、填缝或水管可能有问题，需要检查。
