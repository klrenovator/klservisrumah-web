# 公寓阳台漏到楼下单位

**问题：** 楼下邻居天花滴水的位置正好对着我的阳台。我要负责吗？阳台砖一定要撬吗？

**回答：** 按马来西亚多数 JMB 规定，分层单位业主对自己阳台防水负责。漏水通常是丙烯酸或水泥基防水膜失效、砖缝开裂、阳台地漏堵塞积水，或楼板发丝缝。蓄水测试确认路径。在楼下业主同意下，从下方 PU 灌浆常常能封住发丝缝而不动你的砖。标准阳台全面砸砖重做防水通常要三到五个工作日。

这是**公寓开敞阳台漏到楼下单位**。不是[泳池或湿甲板阳台漏水](/zh/problems/swimming-pool-leak-balcony)，也不是室内[浴室漏水](/zh/problems/leaking-bathroom)。

## 巴生谷公寓阳台为什么会坏

- 丙烯酸或水泥基防水膜经多年紫外线和积水失效。
- 砖缝开裂让雨水进到楼板。
- 阳台地漏堵塞，水顶在门坎。
- 混凝土楼板发丝缝。

管委会维修通知意味着按紧急处理，并保留书面维修记录以便日后索赔。

## 砸砖前先查什么

| 检查 | 为什么重要 |
|---|---|
| 雨后是否积水？ | 积水压垮老化防水膜 |
| 地漏篦子是否塞满叶子？ | 清掉是最便宜的第一测 |
| 滴水跟淋浴还是只跟下雨？ | 室内湿区还是阳台 |
| 砖缝是否已经重勾过？ | 勾过仍漏，下一步是膜或楼板 |

## 维修包括什么

1. 蓄水测试确认漏径。
2. 允许进入楼下时从下方对楼板 PU 灌浆。
3. 防水膜失效则撬砖、做新膜、重铺砖。
4. 清理堵塞地漏，缺滴水线则补上。

全面砸砖 + 新膜 + 重铺通常 **3 至 5 个工作日**。防水适用公布的最长 5 年书面不漏保证。

## 常见问题

### 楼下的损失我要负责吗？
按多数马来西亚 JMB 规则，是的——分层业主对自己的防水负责。尽快修并留下记录。

### 能从楼下 PU 而不砸我的砖吗？
常常可以，需楼下业主同意。发丝缝成功率高。

### 阳台重做防水要多久？
标准阳台通常 3 至 5 个工作日。
