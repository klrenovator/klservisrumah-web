# 推拉窗卡住或推不动怎么办

**问题：** 我家铝合金推拉窗变得很难推——得使劲推，有时还会跳出轨道，或者锁不上。这是怎么回事？

**回答：** 推拉窗卡住，几乎总是出在行走部件或轨道上。滑轮磨损或被灰尘沙粒堵住；轨道本身可能变形或积满杂物；窗框也可能轻微跑位。高层住户的窗扇很重，硬推卡住的窗有让它脱出轨道的风险。解决办法通常是清洁并润滑轨道、更换磨损的滑轮、重新校正或修理锁具——这些小件比换窗便宜得多。

## 推拉窗为什么会卡

### 1. 滑轮脏污或磨损
滑轮承载窗扇重量。时间一长会沾满灰尘沙粒，尼龙轮磨平后，窗扇就变成拖行而不是滑行。

### 2. 轨道里有杂物
灰尘、虫子和硬化的污垢在底轨里堆积，像刹车一样顶着滑轮。

### 3. 轨道变形或损坏
铝合金轨道可能被撞击撞弯，或因多年承重而变形，形成滑轮过不去的卡点。

### 4. 窗框错位
窗框沉降或被撞后，窗扇坐得略不正，跟窗框别着劲。

### 5. 锁具损坏
能推却锁不上的窗，通常是把手或锁扣磨损，而不是轨道问题。

## 读懂症状

| 症状 | 最可能原因 |
|---|---|
| 能推但阻力很大 | 滑轮或轨道脏污 |
| 在某一点跳轨或脱轨 | 轨道变形或弯曲 |
| 只在行程末端卡住 | 窗框或限位错位 |
| 关上了却锁不上 | 锁具或把手磨损 |
| 有摩擦或刮擦声 | 滑轮磨损 |

## 正规维修包括什么

1. **彻底清洁轨道**，并用合适的非油腻润滑剂润滑。
2. **检查滑轮**，把磨损或磨平的轮子换成正确尺寸。
3. **矫直或修复轨道**，如果它已弯曲或损坏。
4. **重新校正窗框**，让窗扇坐正、行走顺畅。
5. **更换锁具或把手**，如果问题出在锁上。

在高层，窗扇脱出轨道是严重的坠落隐患，因此地面以上楼层的窗户作业应交给配有正规吊装与安全设备的专业人员。

## 常见问题

### 你们能换推拉窗滑轮吗？
能。我们备有铝合金和 uPVC 窗常见规格的滑轮，更换磨损的滑轮组让窗户重新顺滑。

### 平开窗你们也修吗？
修。铰链、把手、密封条等所有常见窗型我们都处理，不只推拉窗。

### 卡住的推拉窗能自己修吗？
清洁和润滑轨道适合自己动手。换滑轮通常要抬起窗扇，最好交给专业人员——尤其是地面以上楼层。

### 窗户为什么会突然卡住？
常见诱因是杂物卡进轨道，或滑轮用多年后磨穿。被撞后突然卡住，也可能是轨道弯了。

### 跳出轨道的窗危险吗？
危险，尤其在一楼以上。脱轨的窗扇可能坠落，应修好再使用。
