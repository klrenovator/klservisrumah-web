# 推拉窗卡住：原因与维修

**问题：**为什么推拉窗很难开、推到一半卡住，或会脱轨？

**答案：**推拉窗卡住通常是因为下轨积满污垢、滑轮磨损或损坏、轨道变形、窗扇下沉，或旧润滑剂变黏。正确维修包括清洁轨道、更换损坏滑轮、调整窗扇，必要时校正轨道。

本文同时覆盖 **sliding-window-stuck** 与 **stuck-sliding-window** 的搜索意图。若是铰链窗无法上锁，请参考[窗户锁卡住](/zh/problems/stuck-window-lock)。

## 常见原因

| 原因 | 手感 | 维修 |
|---|---|---|
| 轨道脏 | 有沙粒、滑动不顺 | 清洁并润滑 |
| 滑轮磨损 | 很重、有摩擦声或窗扇下沉 | 更换滑轮 |
| 轨道弯曲 | 窗户在某一点停止 | 校正或更换轨道 |
| 窗扇不方正 | 摩擦窗框或锁对不上 | 调整/复位窗扇 |
| 旧油发黏 | 雨天或热天更难推 | 清洁后重新润滑 |
| 窗扣损坏 | 把手/锁不能操作 | 更换把手或锁 |

## 清洁和维护

1. 在安全范围内开窗，刷走松散灰尘。
2. 吸尘清洁轨道，特别是排水孔。
3. 用湿布擦拭并擦干。
4. 检查滑轮是否扁平、开裂或轴卡死。
5. 如建议，使用干性硅酮润滑剂；避免会吸尘的重油。

不要硬推卡住的窗户。过度用力可能裂玻璃、弯铝框，或把窗扇拉出轨道。

## 什么时候需要换滑轮

以下情况应更换滑轮：

- 窗扇明显一侧下沉。
- 听到摩擦声。
- 窗户反复脱轨。
- 清洁后仍无改善。
- 滑轮开裂、扁平或卡死。

配正确滑轮很重要；不同铝窗品牌使用不同轮径和外壳尺寸。

## 什么时候轨道或框架变形

弯曲轨道常会造成窗户停在某一点。窗户维修师傅有时可校正轨道；严重弯曲或腐蚀的铝轨可能需要更换。如果框架损坏，应评估[铝制推拉窗加工](/zh/services/glass-aluminium/aluminium-sliding-window)是否比反复维修更划算。

## 常见问题

### 可以用油润滑推拉窗吗？
避免重油或黄油，因为会吸灰并变黏。先清洁，必要时使用合适的干性硅酮润滑剂。

### 为什么窗户总脱轨？
通常是滑轮磨损或调整不当、轨道弯曲，或窗扇下沉。师傅可以判断具体原因。
