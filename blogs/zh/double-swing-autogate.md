# 吉隆坡与雪兰莪双开摆动自动门安装

**问题：**双开摆动自动门适合宽阔的有地住宅入口吗？

**答案：**如果两扇门都能安全向内或向外摆动，且不会挡住排水沟、斜坡、停车或人行道，双开摆动自动门很适合宽阔入口。购买前要检查门宽和门重、开启方向、门柱强度、电源、电机类型和安全功能。现场量尺可避免电机太小或门摆到公共通道等常见问题。

本文介绍**双开摆动自动门**。较窄入口请参考[单开摆动自动门](/zh/services/autogate/single-swing-autogate)；摆动空间有限请参考[推拉自动门](/zh/services/autogate/sliding-autogate)。现有自动门故障请参考[自动门遥控器失灵](/zh/problems/autogate-remote-not-working)或[自动门不能关上](/zh/problems/autogate-not-closing)。

## 什么是双开摆动自动门？

双开摆动自动门由两扇铰链门从中线开启，每扇由独立电机或门臂驱动。它在吉隆坡和雪兰莪的有地住宅很常见，因为能提供宽阔清晰的车道开口，并适合传统锻铁或铝门设计。

## 安装前场地检查

| 检查项 | 重要性 |
|---|---|
| 门洞总宽 | 决定门叶宽度和电机负载 |
| 门重 | 电机和铰链必须支撑材料 |
| 开启方向 | 不能撞到公共通道、水沟、斜坡或停车 |
| 门柱尺寸和强度 | 电机和支架需要牢固安装面 |
| 电源 | 控制板附近需要受保护电源 |
| 地面间隙 | 斜坡车道可能导致门叶刮地 |
| 自动门限位 | 开/关位置必须正确 |
| 安全感应器 | 防止夹到车辆或人 |

## 电机类型

### 折臂式电机
外露臂型在马来西亚住宅很常见，较容易装在标准门柱上，也适合较宽门叶。

### 地埋/摇臂电机
隐藏在铰链下方，外观更简洁；但需要良好排水和更扎实的铰链基础，对淹水和安装质量更敏感。

### 直臂式电机
活塞式门臂外观整洁、关门力强，但是否适合取决于门柱距离和几何结构。

正确选择取决于门重、门叶宽度、门柱尺寸和暴晒情况。KL Servis Rumah 会在现场量尺后确认电机型号，而不是假设一套通用。

## 应考虑的安全功能

- 遇阻检测，受阻时停止或倒退。
- 门洞两侧的安全光线/电眼。
- 可调节自动关门时间。
- 停电手动释放。
- 视需要安装警示灯或警笛。
- 加密遥控器。
- 合适时配置备用电源或电池。

自动门是重型机械。运行时应让儿童和宠物远离，所有家庭成员都应知道手动释放方式。

## 安装流程

1. **现场量尺：**测量门洞、门柱、门重和摆动空间。
2. **选择电机：**确定臂型和电机承重。
3. **电源准备：**把受保护线路拉到控制板位置。
4. **安装支架和电机：**牢固安装在坚固门柱上。
5. **设置限位：**设定开关位置和遇阻灵敏度。
6. **安全测试：**测试倒退、遥控器和手动释放。
7. **交付说明：**示范操作、维护和基本故障处理。

## 维护建议

- 保持铰链润滑、无锈。
- 摆动范围不要放石头、花盆或停车。
- 定期测试遇阻检测。
- 检查遥控器和电池。
- 门变慢或出现新异响时安排电机保养。
- 门卡住时不要硬推，先检查铰链和对齐。

## 常见问题

### 双开摆动自动门可以向外开吗？
可以，但不能阻挡公路、人行道或排水沟。空间允许时，许多家庭选择向内开。

### 停电怎么办？
多数自动门有手动释放装置。交付时应说明位置和操作方式。

### 双开门还是推拉门更好？
摆动门需要两侧有门扇摆动空间；推拉门需要沿墙有侧向运行空间，通常由车道布局决定。
