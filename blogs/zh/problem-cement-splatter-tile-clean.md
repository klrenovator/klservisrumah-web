# 装修后水泥渍与粉尘：安全清洁方法

**问题：**如何在不损坏瓷砖、地板和玻璃的情况下去除水泥渍和装修粉尘？

**答案：**水泥渍和填缝白华需要使用合适瓷砖清洁剂、无痕垫和吸尘来小心清除。强酸会侵蚀抛光砖、金属配件和天然石材，因此只能由训练有素的清洁员按正确稀释和冲洗使用。厚粉尘必须先吸尘再拖地，否则会变成研磨泥浆。

## 常见装修后残留

| 残留物 | 常见位置 | 清洁错误风险 |
|---|---|---|
| 水泥渍 | 瓷砖、玻璃、门、框 | 刮伤或酸蚀 |
| 填缝白华 | 新地砖/墙砖 | 令抛光面失光 |
| 硅胶残留 | 玻璃、淋浴屏 | 刮法不对会拖花 |
| 油漆点 | 地板、踢脚线、开关 | 刮除损坏表面 |
| 细水泥灰 | 到处都是 | 干擦会磨花 |
| 保护膜 | 橱柜、框、电器 | 留下黏胶 |

## 安全清洁流程

1. **先干清。**吸尘或清扫粗灰和碎屑。
2. **小范围测试。**确认清洁剂不会伤到瓷砖、金属或玻璃。
3. **使用无痕工具。**白色百洁垫、塑料刮刀和软微纤维比刀片安全。
4. **使用合适清洁剂。**水泥残留可能需要瓷砖安全的无酸或弱酸性清洁剂，并正确稀释。
5. **彻底过水。**清洁剂残留会留下白膜。
6. **耐心重复。**厚水泥渍可能要逐步软化，不能一次硬刮。

## 不要这样做

- 厚水泥灰未吸尘前不要拖地。
- 未受训练不要在抛光砖或玻璃上使用刀片。
- 不要把强酸倒入地漏或倒在金属上。
- 不要整间屋用同一桶脏水。
- 不要忽略新淋浴玻璃上的硅胶或油漆；越久越难清。

抛光石材、大理石、均质砖或特殊表面一定要先测试。天然石材对酸特别敏感。

## 清洁后

- 如果装修粉尘重，更换或清洁冷气滤网。
- 放回物品前擦拭柜内。
- 地板干后检查是否还有填缝白华。
- 清洁期间和之后保持通风。
