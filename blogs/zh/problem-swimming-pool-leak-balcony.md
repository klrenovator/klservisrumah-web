# 阳台与泳池平台渗漏：为什么室外区域最先失效

**问题：** 我家阳台或泳池平台的水渗到楼下天花，为什么同一栋房子里的浴室反而没事？

**回答：** 阳台、露台与泳池平台之所以比室内湿区更早失效，是因为它们直接承受阳光、雨水与完整的温差循环。紫外线会劣化外露的防水层与密封胶，每日的热胀冷缩会让接缝张开，而平坦或找坡不良的地面会积水，持续对每一处薄弱点施压。典型失效顺序是：找坡不足 → 地面积水 → 填缝与墙地交接开裂 → 下方防水层外露劣化 → 水进入楼板。

这是巴生谷公寓与现代有地住宅最常见的防水问题之一，而且从上面看，地面几乎总是「一切正常」。

## 为什么露天平台比室内湿区更早坏

| 因素 | 室内浴室 | 露天阳台／泳池平台 |
|---|---|---|
| 紫外线 | 无 | 持续照射，劣化防水层与密封胶 |
| 温度变形 | 小 | 烈日与暴雨骤冷之间的巨大日温差 |
| 水量 | 可控，排得快 | 全部降雨量，常超过排水口流量 |
| 积水 | 少见 | 找坡平或地漏偏高时非常常见 |
| 接缝应力 | 低 | 高 — 楼板相对墙体持续伸缩 |

结果就是：即使按浴室同等标准施工的阳台防水层，也会提早数年失效。

## 五个常见成因

### 1. 找坡不足造成积水
地面应有坡度，让所有水流向排水口。当坡度做平、做反，或地漏高于周边瓷砖时，每次下雨后水都会滞留。积水会找到每一道细微缺陷，并靠静水压把水分压进楼板。

### 2. 填缝开裂与墙地交接张开
阳台楼板与建筑墙体之间是会相对位移的。该处若用硬性填缝或水泥，必然开裂，直接形成进水通道。这是最常见的入口。

### 3. 瓷砖下方防水层已失效
较早期的阳台常常只做了一层薄水泥基涂料，甚至完全没有防水层，全靠瓷砖与填缝挡水。一旦填缝开裂，下面就什么都没有了。紫外线也会照到上返部位的防水层边缘并使其老化。

### 4. 排水口堵塞或口径不足
阳台地漏容易被落叶、砂粒与毛发堵住。堵塞的排水口会让整个阳台在暴雨时变成浅水池，把水推过门槛并压向墙地交接处。

### 5. 楼板位移裂缝
悬挑阳台板会产生挠曲。多年之后会出现并张开细裂缝，尤其在与主体建筑交接的位置。这正是 PU 注浆常用的部位。

若是泳池平台，还要加上氯化水与持续溅水——池水化学性对密封胶与填缝的侵蚀比雨水更强。

## 渗漏如何诊断

1. **晴天观察。** 如果晴天楼下天花也会湿，应先查水管，而不是平台面层。
2. **蓄水试验。** 临时封堵排水口并在平台上蓄水，同时观察楼下天花。这能确认是否为面层渗漏，通常还能定位具体区域。
3. **坡度检查。** 用水平尺或倒水测试，确认平台到底排不排水。
4. **敲击检查。** 空鼓的瓷砖说明已经脱粘，通常意味着水在砖下已经存在很久。参见[瓷砖空鼓松动](/zh/problems/loose-hollow-tiles)。
5. **接缝与上返检查。** 墙地交接密封胶状态、门口上返高度、地漏套管状况。

## 三种修复方案

### 只做裂缝与接缝处理
若平台排水正常、瓷砖牢固，且渗漏沿明确接缝或裂缝，处理交接部位并对裂缝注浆即可。PU 高压注浆公布价由**每点 RM 300** 起 — 参见 [PU 高压注浆](/zh/services/waterproofing/pu-high-pressure-injection-grouting)。

### 免敲砖表面体系
在现有瓷砖面上施作涂膜或渗透型体系，封闭填缝网络与接缝。适用于瓷砖粘结牢固、基层结构完好的情况。干扰小、工期短，但它无法纠正糟糕的找坡——平台会积水的，还是会继续积水。

### 全面敲除重做防水
拆除瓷砖与找平层，处理楼板基面，用新找平层做出正确坡度，施作防水层并在墙面与门槛处做足上返，进行蓄水试验，最后重新贴砖。这是唯一能同时修正防水层与排水几何的方案。本问题公布区间为 **RM 850 至 RM 12,000+**，[浴室与湿区防水](/zh/services/waterproofing/bathroom-and-wet-area-waterproofing)公布价由 **RM 1,000** 起。

防水工程适用公布的最长 5 年书面防漏保证；适用于您这份工程的范围会在报价单上确认。

## 为什么蓄水试验很重要

蓄水试验是在饰面复原之前，唯一能实证湿区修复是否真正有效的方法。封堵区域、注水至设定深度、静置规定时长，再检查下方空间。任何规模较大的阳台防水工程都应要求做这一步——没做过蓄水试验就验收的防水，等于没有人真正测试过。

## 公寓住户须注意

- 分层大楼的阳台防水通常需要管理层批准，特别是涉及拆除、噪音或共用排水时。
- 部分管理机构会限制外观改动，包括瓷砖颜色与任何抬高的门槛。
- 阳台渗漏影响到楼下单位时，请把源头与修复过程记录存档——这关系到费用分摊。

## 常见问题

### 阳台漏水可以不拆砖吗？
有时可以。若瓷砖牢固、平台排水正常、渗漏来自填缝或明确接缝，免敲砖体系或裂缝注浆可行。若平台积水或瓷砖空鼓，通常必须敲除。

### 为什么积水问题这么严重？
积水会对每一道细裂缝与未密封接缝持续加压，并让面层长期饱水，连很小的缺陷都会过水。修正找坡的重要性，常常不亚于防水层本身。

### 阳台防水要做多久？
小阳台的免敲砖涂层通常一到两天，含养护时间。全面敲除、重新找平、做防水、蓄水试验加重新贴砖，一般约一到两周，视面积与干燥时间而定。

### 做完防水一定要重新贴砖吗？
若防水层在瓷砖下方，就必须拆砖重铺。也有外露型防水体系，但会改变外观，在分层大楼未必获准。

### 泳池平台漏水和阳台漏水一样吗？
机理相同，但泳池平台还要面对氯化水、持续溅水与更高的盐分负荷，因此材料选型更关键。
