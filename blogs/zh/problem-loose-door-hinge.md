# 门下沉、刮地或关不上锁：合页与对位问题解析

**问题：** 我家的门已经往下沉，现在会刮到地板，也扣不上锁。是不是整扇门都要换？

**回答：** 几乎从来不需要。门下沉、刮地或关不上锁，几乎都出自四个原因之一：合页螺丝在木门框里失去咬合、合页磨损或变形、实木门因潮湿膨胀，或者锁扣板（strike plate）已经与锁舌对不上。每一种都有对应做法——换更长的螺丝或打硬木塞、更换合页、刨边并做封边处理、或者重新定位锁扣板。只有当门扇本身分层、变形到无法调整，或门框已经腐朽时，才需要整扇更换。

在吉隆坡与雪兰莪，门是最常见的杂工上门项目之一，也是判断正确后处理最快的项目之一。

## 快速判断

| 症状 | 最可能原因 | 常见做法 |
|---|---|---|
| 门在锁侧刮地，上合页处缝隙变大 | 上合页螺丝已从门框拉脱 | 换长螺丝或打塞后重新拧 |
| 整条锁侧边都发紧，雨天更严重 | 木门吸潮膨胀 | 刨边后对裸露木材做封边 |
| 锁舌碰到锁扣板但进不去 | 锁扣板偏位 | 调整位置或修锉锁扣板 |
| 合页明显松旷、异响，开门时门扇下坠 | 合页磨损或变形 | 更换整套合页 |
| 只有上角蹭门框 | 门框位移或走形 | 用垫片调整合页 |
| 螺丝周围木材发软、松散 | 腐朽或白蚁蛀蚀 | 局部修补或更换门框段 |

## 四个成因详解

### 1. 合页螺丝在门框里失去咬合
这是最常见的原因，而且遥遥领先。每次开门，上合页都以剪切方式承受门扇大部分重量。多年下来，螺纹把周围木材磨空，合页倾斜，整扇门就在锁侧往下掉。

错误做法是把同一颗螺丝再拧进已经变大的孔里——顶多撑一周。正确做法是换用能够到门框衬板后方实木的长螺丝，或者用涂胶硬木榫塞把孔堵实、待胶固化后重新钻孔上螺丝，让螺纹咬进新材料。

### 2. 合页磨损、变形或规格偏小
重门配轻合页，最终一定会变形。廉价冲压合页会在轴节处磨损，产生旷量、异响与明显下坠。实木门与防火门必须按重量配足数量与等级的合页；重门只装两片薄合页，注定失败。

### 3. 潮湿导致木材膨胀
马来西亚的湿度变化足以让实木产生明显位移。干燥时关得好好的门，连下一周雨之后可能就发紧。如果发紧是季节性且轻微的，稍微刨边再做封边处理就够——裸木边吸潮速度远快于封过的边，这也是为什么没做封边的门底最先膨胀。

请注意它与下沉的区别：膨胀是整条边都紧；下沉则是在某个特定角落顶住。

### 4. 锁扣板偏位
锁舌碰到板但进不去，说明板偏了几毫米。这往往是门下沉之后的连带结果——应先修合页，再看锁扣板是否仍需移动。在门本身还在下坠的情况下移板，只是把问题往后挪。

## 一次规范维修包含什么

1. **先确认门框是否结实。** 合页螺丝周围木材发软、松散或空鼓，说明有腐朽或白蚁，往里拧螺丝没有意义。
2. **修复合页固定。** 用长螺丝咬进结构木材，或打硬木榫塞后重新钻定位孔。
3. **磨损就换合页。** 按门扇重量与现有开槽尺寸选配，避免重新开槽。
4. **调整缝隙。** 门扇四周留缝均匀——通常两侧与顶部约 3 mm——这样木材伸缩时不会卡死。
5. **只在必要处刨边，并做封边。** 刨过的木材必须封边或上漆，否则会再次吸潮膨胀。
6. **对位锁扣板并实测。** 从不同角度试关，而不是只推上一次。

## 什么情况才真的要换门

- 门扇分层、底部膨胀，或水已渗入门芯。
- 门扇翘曲到无法与门挡贴合关严。
- 门框有白蚁或腐朽损害，无法局部修补。
- 空芯门反复修补后已经无法咬住任何固定件。

浴室门与厨房门最早损坏，原因是底边长期受潮。如果您的门是从底部往上膨胀，更换通常比反复刨修更划算。

## 常见问题

### 刮地的门可以不换就修好吗？
绝大多数情况可以。重新固定合页、更换合页、刨边与锁扣板对位，能解决大部分刮地与关不上锁的问题。

### 为什么把螺丝拧紧没用？
因为螺纹已经把孔周围的木材破坏了。螺丝要么空转，要么撑一下又脱出。必须打塞，或换用能够到实木的长螺丝。

### 我的门只在雨季发紧，该怎么办？
那是吸潮膨胀。在发紧处轻微刨修，并对所有裸露边缘尤其是门底做封边，是常见做法。在雨季刨得太多，木材收缩后会留下过大的缝。

### 合页你们提供，还是我自己买？
标准合页可由我们提供，也可以安装客户自购的五金。关键是合页等级要匹配门扇重量，尺寸要匹配现有开槽。

### 修合页要多久？
多数不到一小时。若涉及门框修补、多扇门，或更换重型实木门的合页，则需要更长时间。
