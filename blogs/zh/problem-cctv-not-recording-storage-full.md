# CCTV 不录像或画面空白：排查方法

**问题：**为什么 CCTV 停止录像，或某个摄像头显示空白？

**答案：**CCTV 不录像通常是因为录像机存储已满或故障、摄像头断电或断网、录像设置改变，或 DVR/NVR 硬件故障。先检查简单项目——电源、线路、存储状态和摄像头显示；如果录像丢失、硬盘无法识别或多个摄像头离线，就请技术人员处理。

## 快速检查

| 现象 | 可能原因 | 先检查 |
|---|---|---|
| 所有摄像头空白 | 录像机电源或显示器问题 | 电源、HDMI/VGA、电视输入源 |
| 一个摄像头空白 | 摄像头电源、线路或摄像头故障 | 电源适配器、PoE 口、接头 |
| 实时画面正常但不能回放 | 存储或录像计划 | 硬盘状态、录像设置 |
| 录几天后停止 | 硬盘满或覆盖关闭 | 覆盖设置和硬盘健康 |
| 夜间离线 | 红外供电负载或适配器弱 | 电源和线长 |
| 马赛克/断断续续 | 网络差或线路损坏 | 网线、接头、Wi-Fi 信号 |

## 硬盘为什么停止录像

多数 DVR/NVR 系统录像到内置硬盘。常见问题包括：

- 硬盘满了，且循环覆盖未开启。
- 硬盘有坏道或已损坏。
- 录像机电源不稳定。
- 启用动态录像但灵敏度太低。
- 断电后存储格式损坏。

如果系统提示 "HDD not found" 或开机蜂鸣，硬盘或录像机可能需要更换。若需要保留录像，不要自行拆开录像机。

## 电源和网络问题

### 模拟/DVR 系统
检查摄像头电源适配器、BNC 接头、电源分线器和录像机适配器。接头松动会导致单路空白。

### IP/NVR 和 Wi-Fi 系统
检查 PoE 口、网线、路由器和摄像头指示灯。换路由器或信号弱时，Wi-Fi 摄像头可能离线。

PoE 系统中，单个摄像头通常重插网线或换 PoE 口就能恢复；若所有 PoE 摄像头都失效，可能是 NVR 电源故障。

## 技术人员检查什么

1. 录像机电源、启动顺序和报警蜂鸣。
2. 摄像头电源和接头。
3. 线路通断和损坏端。
4. 硬盘健康和格式化状态。
5. 录像计划、动态设置和循环覆盖。
6. 时间日期设置，方便查找录像。
7. 网络或远程查看配置。

以下情况应尽快联系：

## 常见问题

### 为什么 CCTV 只能录几天？
可能是硬盘对摄像头数量来说太小、循环覆盖关闭，或连续录像比动态录像占用更多空间。

### 删除的 CCTV 录像能恢复吗？
不一定。如果硬盘已覆盖录像，恢复可能性很低。应立即停止使用录像机，并询问技术人员硬盘是否仍含数据。

### CCTV 硬盘一般能用多久？
寿命取决于录像负载、热度和电源稳定性。健康检查可在录像丢失前发现早期故障。
