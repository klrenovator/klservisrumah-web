# 雨季屋顶漏水：暴雨当下怎么办，雨停后怎么修

**问题：** 我家屋顶只在雨季暴风雨时漏水，其他时候都正常。下雨当下我该做什么，什么时候才真的能修？

**回答：** 暴雨当下的重点是控水与用电安全，不是维修。先移开贵重物品、用容器接水；若积水靠近任何灯具或线路，到配电箱把该区照明回路关掉；并拍下进水位置。永久性维修——换瓦、重做屋脊灰浆、重打泛水密封、平屋顶重新涂膜——都需要干燥且安全的作业面。雨中攀爬湿瓦屋面非常危险，而任何打在潮湿基面上的密封胶都会失效。正确顺序是：现在控水，干燥后检查，下一波雨来之前完成维修。

本文谈的是雨季这一层面：当下该怎么做、季风天气与一般降雨有何不同、以及雨季前该如何准备屋顶。若您想了解雨水究竟从哪些部位渗进天花，请阅读[下雨后天花漏水](/zh/problems/ceiling-leak-after-rain)。

## 为什么季风雨会找出平时不漏的缝

马来西亚半岛有两个季风季——西南季风约在 5 月至 9 月，东北季风约在 11 月至 3 月，季风交替期还会带来强烈的对流雷暴。马来西亚气象局会发布季节预报与暴雨警报，如果您的屋顶已知有弱点，值得留意。

季风天气下有三件事会改变：

- **风向与风力。** 被风推着的雨会横向甚至向上钻进瓦片搭接缝。一个应付垂直降雨完全没问题的屋顶，遇上时速 60 公里的斜雨可能大量渗水。
- **降雨强度。** 天沟与檐槽是按一定流量设计的。热带暴雨下，半堵塞的天沟会倒灌进屋檐，而不是顺利排走。
- **持续时间。** 长时间降雨会让材料吸饱水。能挡住五分钟阵雨的细微毛细通道，在两小时暴雨中就会开始过水。

这就是为什么一场特大暴雨，可能让多年没问题的屋顶第一次漏水。

## 暴雨中的安全处理顺序

1. **先处理触电风险。** 若水靠近筒灯、吊扇或任何线路，到配电箱关掉该区照明回路。不要触碰仍带电的潮湿灯具。
2. **把水接住。** 滴水处放桶、周围铺毛巾、家具盖塑料布。桶里放一块布可以减少溅水与噪音。
3. **处理鼓包的天花。** 若石膏板天花明显鼓起积水，说明上方已经存水，板材可能突然塌落。先清空下方区域。在稳固位置能安全操作的前提下，戳一个小排水孔可以可控地泄压；否则请远离并等待。
4. **拍照并记录时间。** 进水位置、水量大小、当时风向。这些资料能大幅缩短后续检查时间。
5. **绝对不要爬上屋顶。** 湿的混凝土瓦与陶瓦极滑，瓦片也会被踩裂。马来西亚多数严重的屋顶意外，都发生在雨中想自己补漏的人身上。

## 雨停之后：检查与维修

屋面干燥后，一次完整检查应涵盖：

| 部位 | 检查内容 |
|---|---|
| 屋面瓦片 | 开裂、滑位、缺角、被风掀起；搭接是否破坏 |
| 屋脊与斜脊 | 脊瓦灰浆状况、脊瓦松动、柔性脊带 |
| 天沟与檐槽 | 落叶杂物、青苔、锈蚀、积水、坡向 |
| 泛水 | 与墙体交接处、烟囱与天窗节点、密封胶老化 |
| 防水垫层 | 撕裂、下垂、旧补丁 |
| 屋架结构 | 木檩条与桁架是否受潮腐朽、金属件锈蚀 |
| 平屋顶／阳台板 | 防水层状况、积水、上返部位开裂 |
| 吊顶夹层 | 水流痕迹、檩条水渍、保温层状况 |

## 雨季前的准备：性价比最高的维护

大多数雨季漏水，其实是拖延维护的可预期结果。雨季前建议：

- **清理天沟与落水管。** 最常见也最容易预防的原因。参见[天沟堵塞导致屋顶漏水](/zh/problems/clogged-gutter-leaking)。
- **检查屋脊灰浆。** 水泥勾缝经年紫外线照射会收缩开裂，裂开的勾缝就是斜雨的直接通道。
- **从地面用望远镜或可及的窗口查看**是否有滑位或破裂的瓦片。
- **检查平屋顶与阳台防水层**是否积水、起鼓、上返部位开裂 — 参见[阳台或泳池平台渗漏](/zh/problems/swimming-pool-leak-balcony)。
- **修剪伸过屋面的树枝**，它们会把落叶掉进天沟，刮风时还会磨损瓦面。

## 哪些临时措施可以做，哪些不行

**可作为临时措施：** 由有能力的人在干燥条件下，把防水帆布妥善压重并固定在受损屋面上；室内接水与围挡；关掉受影响回路。

**不能当作解决方案：** 从室内把天花的漏点封住。这会把水闷在屋顶夹层里，腐蚀木檩条、锈蚀金属件，最后从别的地方冒出来。水必须永远在外表面被拦住。

## 常见问题

### 还在下雨时可以修屋顶吗？
像固定防水帆布这类应急控水有时可以，但永久维修不行。密封胶与灰浆无法黏结潮湿基面，湿瓦屋面本身也确实危险。

### 为什么只有大雨才漏？
因为斜雨与高降雨强度突破了只能应付一般降雨的防线——水被推入瓦片搭接缝，天沟也从排水变成倒灌。

### 是屋顶漏还是水管漏？
只在下雨时出现的渗漏指向屋顶、天沟、阳台或外墙；晴天也发生的则指向水管——可用[漏水诊断工具](/zh/gongju/漏水诊断)或阅读[隐藏漏水检测](/zh/bo-ke/ji-long-po-cang-an-lou-shui-jian-ce)。

### 暴雨后多久可以安排检查？
只要屋面干燥且安全即可。雨季期间在两波降雨之间的晴档安排施工，是常见做法。

### 需要报保险吗？
取决于您的保单，以及损坏属于风灾还是自然老化。带日期的进水照片与书面检查报告，能支持您决定提出的任何索赔。
