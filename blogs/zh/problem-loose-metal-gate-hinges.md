# 金属门铰链松动下垂：维修还是更换？

**问题：**为什么金属门会下垂、刮地，或让自动门电机很吃力？

**答案：**金属门下坠通常是因为铰链或铰链销磨损、焊口开裂、门柱支架移位，或门被障碍物卡住后硬推。维修可能包括重新焊接、更换铰链销/轴承、加垫片调整门柱支架，或重新对齐门；严重生锈或门框扭曲则可能需要换铰链或铁工。

本文讲**金属门铰链**。遥控器或电机问题请参考[自动门遥控器失灵](/zh/problems/autogate-remote-not-working)；门关不上请参考[自动门不能关上](/zh/problems/autogate-not-closing)。

## 铰链磨损迹象

- 开关时门刮地。
- 抬起门扇时有松动间隙。
- 自动门电机很吃力，或门关上前停止。
- 锁和锁扣对不上。
- 铰链板周围焊口开裂。
- 门发出摩擦或尖锐声。

## 常见原因

| 原因 | 发生情况 | 维修方式 |
|---|---|---|
| 铰链销/衬套磨损 | 门下沉倾斜 | 更换销/衬套 |
| 焊口开裂 | 铰链板移动 | 重焊或加固 |
| 门柱螺栓松动 | 整个铰链移位 | 重新锚固或焊接 |
| 门框弯曲 | 门扇不方正 | 校正或加工 |
| 金属生锈 | 材料强度下降 | 切掉并更换局部 |
| 轨道/滑轮故障 | 推拉门卡住 | 调整轨道/滑轮 |

## 为什么要尽早修

下垂的门不只是刮地。它会增加自动门电机负荷、磨损锁和锁扣、扩大螺栓孔，还可能裂开门柱支架。换电机的费用远高于铰链维护。已公布的[自动门电机更换与维修服务](/zh/services/autogate/autogate-motor-replacement-and-service)从 **RM 950** 起。

## 铁工检查包括什么

1. 抬起每扇门检查铰链间隙。
2. 检查铰链销、衬套、轴承和焊口。
3. 检查门柱锚固和砖墙。
4. 测量门框是否方正。
5. 先手动测试门，再测试电机。
6. 建议重焊、换铰链或重新对齐。

## 维修还是换铰链？

**维修就足够：**门框扎实，问题只是销磨损、螺栓松或焊口裂。

**更换更好：**铰链严重生锈、门框扭曲、反复焊接仍失败，或门已经无法与电机和锁对齐。

## 安全提示

如果金属门扇明显下沉或卡住，不要继续操作自动门。切换到手动模式，并让儿童远离，直到门修好。

## 常见问题

### 下垂的门可以不换吗？
通常可以。只要门框和门柱仍然扎实，磨损的销、松动螺栓和开裂焊口都可以修。

### 为什么自动门走到一半停？
电机可能检测到来自下垂门、障碍物或轨道问题的额外阻力。不要继续硬推。

### 门铰链维修要多少钱？
