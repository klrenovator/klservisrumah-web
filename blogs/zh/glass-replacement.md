# 吉隆坡与雪兰莪窗户玻璃更换

一块玻璃裂了，不必换整窗。框还方、胶条槽还在，可以只换玻璃。

**直接回答：** KL Servis Rumah 更换破碎、开裂或失效的窗户玻璃，从 **RM 200** 起，按原尺寸厚度匹配，或在同一框内升级为茶玻、磨砂或钢化。

相关维修：玻璃完好但仍进雨，做 [窗户密封条更换](/zh/services/window-repair/window-seal-replacement)；执手、铰链与滑轮见 [窗户维修](/zh/services/window-repair)。

## 什么时候该换玻璃

- 看得见的裂纹、崩边或破碎。
- 撞击造成的破洞（球、梯子、树枝）。
- 中空玻璃**夹层**起雾或结露 — 单元密封已失效。
- 严重刮花或旧膜去不掉。

玻璃完好只漏风，不要先换玻璃 — 那通常是 [橡胶密封条](/zh/services/window-repair/window-seal-replacement)。

## 白玻、茶玻、磨砂还是钢化？

| 玻璃 | 典型用途 | 说明 |
|---|---|---|
| 4–5 mm 透明退火玻璃 | 普通住宅窗 | 碎成尖片 — 不适合湿区门 |
| 茶色 / 灰色 / 绿色 | 西晒房、眩光 | 减少部分热量 |
| 磨砂 | 卫生间、楼梯、对邻居视线 | 透光不透视 |
| 钢化 | 门、低窗台、湿区、大板 | 碎成小颗粒；交期 2–5 个工作日 |
| 夹层 | 安防 / 头顶 / 部分商铺 | 破了仍粘在一起 |

淋浴屏不用普通退火玻璃。淋浴工程见 [玻璃与铝业](/zh/services/glass-aluminium)。

## 当日还是订做

- **当日（有地、常见尺寸）：** 可按洞口裁的 4 mm、5 mm 白玻或茶玻。
- **订做：** 钢化、夹层、特殊厚度或中空单元。我们测量，不挡风雨就先封板，厂片好了再装（通常 2–5 个工作日）。

高层公寓必须从外侧作业时，可能需要登高设备。看到洞口后再报价。

## 玻璃怎么换

1. 测量厚度、类型（退火还是钢化 — 钢化角标常在角落）和企口。
2. 旧片贴膜，拆压条或胶条，抬出玻璃。
3. 清理企口；放垫块，让新片不直接坐在铝材上。
4. 就位新玻璃；装回压条；胶条已硬化则一并换新。
5. 清洁并确认窗扇能关上，不挤压新玻璃。

旧硬胶条里装新玻璃还会漏。需要一起换胶条我们会说明。

## 常见问题

### 茶玻能配上其他窗格吗？

常见灰、茶色我们按库存尽量接近。晒褪色的旧玻可能无法完全一致。

### 只裂在角落，能先放着吗？

裂缝会走。高窗或门上，下一场暴雨前换掉。

### 这等于换一樘新铝合金窗吗？

不等于。新框是 [玻璃与铝业制作](/zh/services/glass-aluminium)。本服务沿用原框。
