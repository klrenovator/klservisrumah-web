# 天沟堵塞导致屋顶漏水或溢水怎么办

**问题：** 下大雨时，水会从天沟边缘溢出、顺着墙面流下，有时下面天花板也会受潮。是天沟堵了，还是另有原因？

**回答：** 天沟边缘溢水，几乎总是下面两种情况之一：堵塞使雨水无法流到落水管，或天沟失去坡度（斜度），雨水积在沟内流不出去。在马来西亚有地住宅里，落叶、青苔和灰尘堆积是最常见的原因。当雨水溢出或倒灌时，会渗入檐口木板，顺着墙流下，最后渗到天花板或墙体内侧——这时「天沟问题」就变成了室内漏水。解决办法是清除杂物、恢复朝向落水管的坡度，再修复被积水泡坏的木板或泛水（flashing）。

## 为什么马来西亚的雨天沟容易溢水

马来西亚的雨又急又短，对天沟的压力与绵绵细雨完全不同。小雨时排水顺畅的天沟，遇到倾盆大雨可能严重溢水。

- **树叶、树枝和青苔**堆积在天沟最低处和落水管口。
- **坡度丢失**意味着天沟不再朝落水管倾斜，雨水积着不流。
- **下坠段**形成小洼地，像小水坝一样最先积攒杂物。
- **落水管堵塞**使水倒灌，直到从天沟边缘溢出。
- **天沟过小**即使干净也承受不了季风级的水量。

## 判断是天沟问题的迹象

| 迹象 | 通常含义 |
|---|---|
| 只在某一点溢水 | 局部堵塞或某段下坠 |
| 整条沟都溢水 | 坡度丢失，或天沟对屋顶来说过小 |
| 水从天沟后面流下 | 天沟脱离檐口，或泛水失效 |
| 屋檐线下方天花板或墙受潮 | 水正在渗回建筑结构 |
| 天沟里长出植物 | 杂物长期堆积 |
| 天沟明显倾斜或脱离 | 支架或檐口板失效 |

下雨时屋檐线下方天花板受潮值得重视——这说明水已经进入建筑围护结构，而不只是溅在外面。同类问题的室内表现可参见[雨后天花板漏水](/zh/problems/ceiling-leak-after-rain)。

## 您可以安全自查的项目

天沟作业往往涉及高空，这也是大多数业主不该在暴风雨里搬梯子拿水管爬上去的原因。站在地面，您仍可以：

1. **观察下雨时水从哪里溢出**，记下是一处还是整条。
2. **查看落水管出口**——如果下雨时落水管不出水，说明它堵了。
3. **从街对面看天沟线**，有没有明显下坠、倾斜或长植物。
4. **检查室内**天花板或屋檐线下方墙面有没有新的潮湿痕迹。

如果天沟需要清理或重新调坡，而且高度超过一层楼，请交给配有正规梯子和安全设备的团队，而不是自己凑合。

## 正规的天沟维修包括什么

好的天沟作业绝不只是舀舀树叶。工作通常包括：

1. **清理每段天沟和落水管**的杂物，并放水测试排水。
2. **重新调整坡度**，让每段都能排到落水管而不积水。
3. **重新固定下坠段**，更换生锈的支架或卡扣。
4. **封住转角与落水管接口的漏水点**。
5. **维修或更换檐口板**，如果积水已泡烂木板。
6. **在有大树悬垂的住宅加装天沟防护网**，减缓日后再堆积。

## 常见问题

### 在马来西亚天沟该多久清理一次？
至少每年两次——主季风季前后各一次；屋顶上方有树木悬垂则要更频繁。

### 你们安装天沟防护网吗？
会。附近有树的有地住宅建议加装防叶网，能明显减少天沟需要清理的频率。

### 天沟堵塞真的会漏进屋里吗？
会。当水溢出或倒灌时，会渗入檐口板、从天沟后面流进墙体空腔或天花板空间，在室内表现为潮湿痕迹。

### 清天沟能自己动手吗？
低矮单层天沟、梯子稳固的情况下可以自己清。凡涉及高空、重新调坡、下坠段或檐口板维修，最好用正规设备处理。

### 只清理就能止住溢水吗？
只有在堵塞是唯一原因时才行。如果坡度不对或某段下坠，还必须重新调坡并加固，否则还会再溢。
