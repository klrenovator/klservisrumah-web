# 电动门关不上或电机不停运转怎么办

**问题：** 我家电动门能正常开，却关不上，或者电机一直转不停，有时还会到一半自己弹回来。是电机要坏了吗？

**回答：** 不一定——能开却关不上的门，通常是控制或安全部件的问题，而不是电机磨损。四个最常见的原因是：限位开关损坏，不再告诉电机该在哪里停；防夹感应器被挡住或错位，不停触发安全回弹；电机电容失效，带不动门关闭；或遥控器／控制板故障发出错误信号。解决办法是检测并更换损坏的部件——往往是个不贵的小件——而不是换掉整台电机。

## 电动门为什么关不上

| 成因 | 典型线索 |
|---|---|
| 限位开关损坏 | 电机冲过停止点，或永远不停 |
| 防夹感应器被挡 | 门像碰到障碍一样回弹 |
| 电机电容失效 | 电机嗡嗡响却没力气关门 |
| 遥控器或控制板故障 | 门时有时无地无视关门指令 |
| 安全对射错位 | 每次都在同一点回弹 |

## 报修前先自查

1. **查看门两侧的安全感应器**（对射光电）。灰尘、蜘蛛网或撞歪的对位，都会让门不肯关。
2. **听电机声。** 嗡嗡响却不动，或运行变慢，指向电容。
3. **试用手动释放**，让门在故障期间能手动开合——这对安全很重要。
4. **记下是每次都这样还是偶尔**——间歇性故障常指向控制板或遥控器。

## 技术人员会做什么

电动门技术人员通常会：

- 检测并更换限位开关，让电机在正确位置停下。
- 清洁并重新校正安全感应器与对射光电。
- 电机乏力时检测并更换电容。
- 控制板发出错误信号时重新编程或更换。
- 保养电机与轨道，并检查铰链、轮子运转是否顺畅。

通常是安全感应器或对射光电脏了、错位或失效，让门以为有障碍。

危险——停不下来的电机会过热、损坏自身或拉扯门体。应立即断电并尽快检修。
