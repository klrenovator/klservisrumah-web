# 厨房或浴室排水堵塞：水流慢与倒灌

**问题：** 水排得很慢，积在水槽或淋浴盘里，或者开不止一个龙头就会倒灌。这是局部堵塞，还是主管出问题？

**回答：** 单个水槽或花洒变慢，通常是厨房 P 弯和水平管里的油脂，或浴室存水弯里的头发。冲水时另一个地漏冒水泡，或多个排水口一起倒灌，说明是共用污水管，或某段管子下垂在积渣。机械疏通加酶制剂是安全的第一步。强碱疏通剂可能损坏老旧 PVC 接口，在封闭的马来西亚浴室里也不安全。

本页讲的是**厨房和浴室废水排得慢**。马桶冲不干净是另一回事——见[马桶冲水不畅](/zh/problems/toilet-not-flushing)。马桶完全堵住、水位上涨见[马桶堵塞](/zh/problems/blocked-drain-toilet)。

## 马来西亚住宅为什么容易堵

- **厨房油脂**在 P 弯和橱柜后长水平管里冷却凝固。
- **头发**缠在浴室存水弯和淋浴排水第一道弯。
- **湿巾和卫生用品**进入马桶管——它们不会分解。
- **管子破裂或下垂**形成一个低点，即使清了存水弯，渣还会沉在那里。

“就倒这一次”的烹调油是厨房最常见原因。在约 27 °C 的管子里它不会保持液态。

## 局部堵还是共用管？

| 迹象 | 含义 |
|---|---|
| 只有厨房水槽慢 | 那个存水弯或那段管有油脂 |
| 只有淋浴盘积水 | 头发或淋浴排水 |
| 用第一个时第二个地漏咕噜或上涨 | 共用管半堵 |
| 多个排水口同时倒灌 | 主管或检查井 |
| 室内有下水道味 | 存水弯干了，或污水在漏 |

## 可以安全做的

1. 取下水槽滤网，清掉明显的头发和食物。
2. 单洁具用揣子，先用湿布堵住溢水口。
3. 洗碗后放热水——不能代替不倒油。
4. 老 PVC 不要用强碱“管道通”。

如果多个排水口一起失效，先别再倒水，打电话——你可能在往已堵的主管里灌水。

## 专业疏通包括什么

1. **手动疏通簧 / 通条**清存水弯和第一段管。
2. **对管道安全的酶处理**，在机械清通之后使用。
3. **高压水射流**对付顽固厨房油管。
4. **内窥镜检查并修管**，管子下垂或破裂时。

## 常见问题

### 化学疏通剂安全吗？
强碱可能损坏老 PVC 接口，密闭空间也不安全。机械清通加酶更持久、更安全。

### 疏通厨房排水多少钱？
手动疏通 RM 150 至 RM 250。整条厨房管高压冲洗 RM 350 至 RM 700。

### 怎样预防厨房再堵？
不要把烹调油倒进水槽。用滤网。放热水，并每月做一次酶处理。
