# 自动门遥控器失灵？快速检查与维修

**问题：**为什么自动门遥控器不能开门或关门？

**答案：**最常见原因是遥控器电池没电，或遥控器需要重新配对。如果墙键能用而遥控器不能用，问题通常在遥控器、电池、天线或接收器；如果遥控器和墙键都不能用，就可能是控制板、电机、电源或安全感应器需要维修。

## 先做这些检查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| 遥控器灯变暗/不亮 | 电池没电 | 更换电池 |
| 近距离行、远距离不行 | 天线或距离问题 | 检查天线位置 |
| 一个遥控器不行，另一个行 | 遥控器故障 | 重新配对或更换 |
| 所有遥控器不行，墙键正常 | 接收器/天线问题 | 检查接收器和接线 |
| 完全没反应 | 电源、控制板或电机故障 | 检查断路器并请师傅 |
| 门启动后又倒退 | 障碍物或安全感应器 | 清理轨道并检查感应器 |

## 更换遥控器电池

使用正确电池型号，通常是小型锂电池。更换后分别在正常距离和靠近控制板处测试。如果遥控器摔过或进过水，按键或内部触点可能损坏。

## 重新配对

有些遥控器在换电池、电涌或控制板重置后会丢失编码。新备用遥控器也需要让接收器学习。添加新遥控器时保留所有旧遥控器，因为部分系统会先清空记忆再重新学习。

## 距离和天线问题

如果遥控器只能在很近处使用：

- 确认接收器天线竖直，没有被金属夹住。
- 更换遥控器电池。
- 检查接收器附近是否新增金属结构、车辆或电子设备。
- 避免在远处反复按按钮，某些系统可能因此不同步。

## 什么时候涉及电机或控制板

如果墙键也失效，检查：

- 主电源和 MCB/断路器。
- 自动门电机是否有嗡嗡声但不移动。
- 门是否被卡住或脱轨。
- 手动释放装置是否处于开启状态。
- 最近是否有雷击电涌或水浸。

如果电机锁死，不要硬拉门；按制造商方式使用手动释放。

## 常见问题

### 为什么遥控器时好时坏？
通常是电池、距离或接收器天线问题；附近金属或电子设备干扰也会降低稳定性。

### 可以买通用自动门遥控器吗？
有些系统可使用兼容遥控器，但频率和编码必须匹配，接收器可能还需重新配对。

### 门能开但不能关怎么办？
检查障碍物、安全感应器和关门限位设置。如果没有明显障碍却倒退，应请技术人员检查控制板和感应器。
