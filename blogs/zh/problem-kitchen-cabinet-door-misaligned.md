# 厨房橱柜门错位或关不拢怎么办

**问题：** 我家橱柜门变得不齐——一扇比另一扇高，角上互相摩擦，或者关不紧。我需要换门板，还是整个厨房都要换？

**回答：** 橱柜门错位几乎从来不是换厨房的理由。绝大多数情况下问题出在铰链或柜体，而不是门板本身。铰链经年累月开合会磨损、跑位；柜体会随建筑沉降或吸湿轻微移动；门板上挂重物（锅碗瓢盆）则会让它下坠。解决办法通常是调整或更换铰链、加固柜体、重新校平门板——这些工作量比换新橱柜便宜得多。

## 橱柜门为什么会跑偏

### 1. 铰链磨损或松动
最常见的原因。欧式隐藏铰链的螺丝会慢慢松动，内部弹簧磨损后门板不再自动吸合。一扇原本闭合利落、如今低了几毫米的门，通常就是铰链问题。

### 2. 柜体移动
橱柜固定在墙面并彼此相连。建筑沉降，或马来西亚厨房湿度反复变化时，柜体可能轻微扭转——足以让门板错位。

### 3. 承重过载
在门板上挂沉重的锅、罐子或叠放的碗碟，会随时间的推移让它下坠，并压迫铰链安装点。玻璃门尤其敏感。

### 4. 铰链型号不对
给重门或玻璃门配薄而轻的铰链，会提早疲劳。正确型号与数量的铰链，比多数业主以为的更重要。

## 调校还是更换

| 情况 | 通常处理 |
|---|---|
| 单扇门略低，铰链完好 | 调整铰链螺丝 |
| 门关不紧，缓冲失效 | 更换铰链或阻尼器 |
| 使用多年后门互相摩擦 | 重新校平并重新挂装 |
| 柜体明显松动或移位 | 重新固定柜体 |
| 门板本身变形或开裂 | 更换门板 |
| 整排多扇门都旧了 | 厨房翻新（门板与五金） |

如果厨房大多数门都已老旧但柜体仍牢固，[仅更换门板与五金的厨房翻新](/zh/services/kitchen-cabinet/kitchen-makeover-doors-and-hardware-only)往往比整体重做更划算。

## 正规维修包括什么

1. **逐扇检查门板**的下坠、摩擦与门扣情况。
2. **先紧固并调整铰链**——这能解决大多数单扇门的问题。
3. **更换磨损或失效的铰链**以及必要的缓冲阻尼器。
4. **重新固定柜体**，如果柜身已移位或脱离墙面。
5. **重新校平并挂装门板**，让上下缝隙均匀。

## 常见问题

### 你们能修缓冲铰链吗？
能。我们更换磨损的阻尼器与铰链，换成优质的缓冲五金，让门轻轻合上并保持关闭。

### 你们修现有橱柜还是只装新的？
两者都做。我们调校和维修现有橱柜——铰链、门板与柜体——也安装新橱柜。

### 调铰链和换门哪个便宜？
几乎总是调校更便宜。只有门板变形、开裂或泡水才需要换；大多数错位都是铰链或柜体的问题。

### 潮湿厨房里门为什么容易错位？
木材与板材随湿度胀缩，反复膨胀会松动铰链螺丝并轻微移动柜体。

### 调铰链要多久？
单扇门通常不到一小时就能调好。整间厨房多扇门加上柜体检查，一般需要半天。
