## 我们提供的锁匠服务

- **[智能锁安装](/zh/services/locksmith/smart-lock-installation)** — 密码、蓝牙、Wi-Fi 或指纹锁，含 App 配对与用户录入。从 RM 420 起。
- **[执手锁 / 呆锁更换](/zh/services/locksmith/mortice-deadbolt-lock-replacement)** — 拆除旧锁，安装新的 Yale、Imperial 或 Häfele 锁，配 3 把钥匙。从 RM 220 起。
- **配钥匙与换锁芯** — 为现有锁芯配新钥匙，或改钥匙使旧钥匙失效。从 RM 30 起。
- **紧急开锁（有地住宅）** — 无损开启，需所有权证明。从 RM 180 起。

门扇刮地或下垂是 [门](/zh/services/door) 的问题。只修铰链：[门铰链与锁具维修](/zh/services/handyman/door-hinge-and-lockset-repair)。锁有电但打不开： [智能锁无法使用](/zh/problems/smart-lock-not-working)。

## 机械锁还是智能锁

| | 机械执手锁 / 呆锁 | 智能锁 |
|---|---|---|
| 最适合 | 简单可靠、租客、次卧 | 大门、常有访客、不想带钥匙 |
| 安装起步 | 从 RM 220 起 | 从 RM 420 起 |
| 常见故障 | 锁芯磨损、螺丝松、锁扣不对 | 电池没电、门变形、Wi-Fi 不稳（若用联网） |
| 搬家后 | 换锁芯从 RM 30 起 | 删除旧指纹 / 密码 |

门扇合不上就装智能锁，锁会坏。开新锁体前我们先查门是否对齐。

常装品牌：**Samsung、Yale、Igloohome、Solity、Häfele、Kaiser、Philips**。

## 何时换锁、换锁芯，或只配钥匙

- 锁还好、只要备用钥匙：**配钥匙**。
- 刚搬入、钥匙丢了、或装修工人还留着旧钥匙：**换锁芯**。
- 锁芯磨损、锁舌弯曲、或要换类型：**换锁**。
- 锁扣板只有短螺丝钉在软框上：**加固门框** — 锁只和门框一样结实。

## 紧急被锁门外

吉隆坡与雪兰莪有地住宅，视技师档期常常能当天无损开门。开门前我们要求**所有权证明**（身份证、水电账单，或与地址相符的带照片证件）。公寓方面管理处常有万能钥匙 — 我们可以与他们协调。

没有证明，不开门。

## 常见问题

### 马来西亚公寓最适合哪款智能锁？

没有单一最佳品牌。标准开孔的公寓门常选 Solity 或 Häfele，少改门。有地大门常见 Yale、Samsung 或 Igloohome 锁体型号。

### 能留锁只配钥匙吗？

锁芯健康就可以。

### 被锁在公寓门外怎么办？

若管理处有权限先联系他们。我们仍可上门，仍需要您有权进入的证明。

### 智能锁安装要多久？

开孔匹配约 30–60 分钟；新开锁体 1.5–2 小时。
