# 吉隆坡与雪兰莪防火板门安装

防火板门（HDF 表皮工程木门，表面贴防火板）是马来西亚公寓里常见的卧室和储物间门扇。它比实心柳安轻，在空调房里尺寸更稳定，能做出平整现代的门面。

说明：这里的“防火板”指 laminate / HPL 饰面，**不是**认证防火门。认证防火门是另一项。

**直接回答：** KL Servis Rumah 供应并悬挂防火板门，从 **RM 250** 起，门框完好时可装在现有框上，含铰链作业与锁具对齐。

要质量和可翻新表面，选 [实木门](/zh/services/door/solid-timber-door-installation)。刨修与防火等级见 [门维修与安装](/zh/services/door)。

## 起步价包含什么

从 RM 250 起通常包括：

- 按测得企口尺寸的 HDF 表皮工程木门扇，防火板面。
- 门框可再利用时挂在现有框上。
- 铰链与均匀缝隙调校。
- 尽可能与现有锁扣板对齐锁舌。

新门框、套线、玻璃插芯或新锁另计。防火洞口需要认证防火门，不是卧室防火板门扇。

## 为什么防火板门适合公寓

巴生谷公寓白天开空调，关空调后又潮湿。实木室内门会涨、会刮。工程木防火板门扇：

- 季节间变形更小。
- 好擦 — 儿童房实用。
- 颜色一致，整条卧室走廊统一。

代价：表面不能像实木那样打磨翻新。

## 什么时候不要用卧室防火板门

- **排气差的湿卫生间** — 水积在下挺，边缘会涨。
- **防火洞口** — 厨房 / 逃生门必须是认证套装。
- **大门** 如果您要实心防盗扇和深锁体装 [呆锁或智能锁](/zh/services/locksmith)。

如果唯一问题是新铺 [地板](/zh/services/flooring) 后刮地，先做从 RM 120 起的刨门。见 [门刮地板](/zh/problems/door-scraping-floor)。

## 我们怎么装

1. 测量企口、厚度和锁高。
2. 确认颜色，以及现有门框套线是否保留。
3. 需要时修门扇（出厂门往往略大）。
4. 整扇门用三只铰链悬挂。
5. 安装或复用锁；测试锁舌与反锁。
6. 检查完成地面净空。

## 常见问题

### 能留旧框旧锁吗？

通常可以。我们量锁体。新门厚度不同时，锁舌可能需要不同锁扣板或新锁。

### 防火板门是空心的吗？

许多工程木门是蜂窝或管状芯，锁位有实木锁块。不是实木，所以更轻更便宜。

### 要多久？

旧框上换一两扇，门到场后常常一次上门完成。
