# 入墙衣柜门关不严或错位怎么办

**问题：** 我有一扇入墙衣柜门关不严——它比另一扇门突出来一点，跟门框摩擦，或者会自己弹开。是衣柜坏了吗？

**回答：** 衣柜门关不上通常是定位问题，而不是结构损坏。三个主要原因是：安装时柜体没有真正调平、铰链磨损或跑位、以及门板在马来西亚潮湿气候下变形。各自的处理不同：调平并重新固定柜体、调整或更换铰链、或刨修后重新挂装门板。大多数情况下，衣柜都能原地修好，成本远低于重做。

## 衣柜门为什么关不上

### 1. 柜体不平
入墙衣柜装在天地之间，哪怕差几毫米，也会让一扇门比另一扇突出。这是老安装里最常见的原因。

### 2. 铰链磨损
门每天开关很多次，铰链螺丝和弹簧会跑位、磨损。一扇原本关得好、如今略低的门，几乎总是铰链问题。

### 3. 门板变形
木质板材会随天气吸湿和放湿。潮湿房间里又高又薄的门板会轻微弯曲，不肯贴合。

### 4. 搁板超载
衣柜底部放重物或搁板下坠，会让柜身轻微扭转——足以让门错位。

## 读懂症状

| 症状 | 最可能原因 |
|---|---|
| 门在铰链一侧偏低 | 铰链磨损或松动 |
| 两扇门互相突出来 | 柜体不平，或铰链跑位 |
| 门在上角或下角摩擦 | 门板变形，或柜体扭曲 |
| 门关上了却又弹开 | 铰链或门扣错位 |
| 四周缝隙不均 | 柜身移位或不成直角 |

## 正规维修包括什么

1. **检查柜体**水平度，若已移位则重新固定。
2. **先紧固并调整铰链**——这能解决大多数情况。
3. **更换磨损铰链**，或按需加装缓冲五金。
4. **只在确实变形时刨修门板**，尽量少刨。
5. **重新挂装并校平**，让缝隙均匀。

对于严重变形或开裂的门，换掉单扇门板，比反复刨一块还会继续变形的门更划算。

## 常见问题

### 你们能修现有的衣柜吗？
能。我们维修和调校入墙衣柜、更换铰链、校平门板、刨修变形面板——大多数情况无需重做。

### 你们用缓冲铰链吗？
用。我们安装优质的缓冲系统，让门轻轻合上并保持关闭。

### 为什么衣柜门只在潮湿天气出问题？
木材与板材遇湿膨胀。干燥天气里勉强能关的门，空气一潮就可能弯曲或卡住。

### 变形的门就废了吗？
一般不会。轻微变形可以通过刨修和重新挂装纠正；只有严重开裂或重度变形的门板才需要更换。

### 修一扇衣柜门要多久？
单扇门的铰链调校通常不到一小时。调平柜体或刨修门板一般需要一到两次上门（含收尾）。
