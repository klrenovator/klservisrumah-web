# 门刮地板或关不上锁怎么办

**问题：** 我家卧室门开始刮地板，不抬一下门就锁不上。需要换门吗？

**回答：** 几乎从来不需要。门刮地板或对不上锁，是门跑位了，原因通常是下面三种之一：门受潮膨胀、铰链松动导致门下沉、或锁扣片移位使锁舌对不上孔。标准的处理是刨门的底部、紧固或更换铰链、重新定位锁扣片。除非门本身真的损坏，否则都不必换门。

## 门为什么会开始拖地

### 1. 受潮膨胀
木门在马来西亚气候下吸湿会膨胀。干燥天气里轻松离地的门，长时间受潮后可能开始拖地——这是最常见也最季节性的原因。

### 2. 铰链松动
铰链螺丝在成千上万次开关后松动。当上铰链松了，门在锁舌一侧下沉，就会拖地。

### 3. 地面高度变化
新铺地板、加高门槛，或地面沉降，都会减少门下的净空。

### 4. 锁扣片错位
如果门能关却锁不上，门框上的锁扣片可能滑位了，锁舌对不上孔。

## 读懂症状

| 症状 | 最可能原因 |
|---|---|
| 只在潮湿天气拖地 | 门膨胀 |
| 在锁舌一侧下沉 | 上铰链松动 |
| 铺新地板后才拖地 | 净空变小 |
| 能关但锁不上 | 锁扣片错位 |
| 锁舌偏高或偏低才咬合 | 铰链磨损或门框移位 |

## 正规维修包括什么

1. **检查铰链**，先紧固或更换松动的螺丝。
2. **查看门四周的缝隙**，判断是下沉还是膨胀。
3. **如果原因是膨胀或净空不足，就刨门的底部**，尽量少刨。
4. **重新定位锁扣片**，让锁舌利落咬合。
5. **地板升高留下底部缝隙时，加装门底密封条**。

对重门或装了智能锁的门，刨修和重新挂装最好交给专业人员，以免打乱锁的对位。

## 常见问题

### 你们能不下门就刨门吗？
小幅度调校可以。较重的门或带智能锁的门，可能需要暂时卸下，才能做得精准。

### 你们修防火门吗？
修。防火门维修在刨修或五金作业期间会保持防火等级。

### 为什么门只在下雨后拖地？
潮气让门膨胀。如果干燥天气又能离地，那就是季节性的膨胀，而非铰链或门框缺陷。

### 该刨门还是先修铰链？
先修铰链。如果门在锁舌一侧下沉，紧固上铰链往往就能恢复净空，不必刨料。

### 膨胀的门能封住、防止以后再胀吗？
封边良好、刷了优质漆或清漆的门，受潮影响较小。刨底后再重新封住底边是常见做法。
