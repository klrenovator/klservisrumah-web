# 监控不录像或录像缺失怎么办

**问题：** 我的摄像头有实时画面，但回放时没有录像，或文件缺失、损坏。这是怎么回事？

**回答：** 实时画面正常但录像异常时，摄像头和电源通常都没问题——故障出在录像这一侧。最常见的原因是硬盘（HDD）损坏或正在损坏、录像计划被关闭或被覆盖、保留天数设置得太短把录像过早删掉、网络故障导致录像机收不到画面、或摄像头固件停止正常写入。解决办法是检查硬盘健康、重新确认录像计划与保留天数，并逐一测试每台摄像头的录像链路——监控技术人员通常一次上门就能完成。

## 系统为什么停止录像

| 成因 | 典型线索 |
|---|---|
| 硬盘损坏 | 无法回放，或录像机报硬盘错误 |
| 录像计划关闭 | 实时画面正常，但从不录像 |
| 保留天数太短 | 老录像缺失，近期的还在 |
| 网络故障 | 部分或全部摄像头从录像机掉线 |
| 录像机电源问题 | 录像机重启或丢失录像 |
| 摄像头固件问题 | 只有某一台停止录像，其余正常 |

## 报修前先自查

1. **确认录像机已开机**、电源正常——录像机重启会丢录像。
2. **检查录像计划**。时间不对或计划被误关，是很常见的隐性原因。
3. **看硬盘状态。** 多数录像机会显示硬盘健康或错误提示。
4. **从一台摄像头试回放**，判断故障是所有摄像头还是一台。
5. **记下从何时开始**——断电后、固件升级后，还是网络改动后。

## 监控技术人员会做什么

技术人员通常会：

- 检测硬盘，损坏则更换，并先转移或尝试恢复重要录像。
- 重新配置录像计划与保留天数，让录像按预期时长保存。
- 因固件引起时，升级摄像头与录像机固件。
- 检查到录像机的网络连接与供电。
- 通过逐台回放测试片段，确认每台摄像头确实在录像。

## 常见问题

### 能恢复丢失的录像吗？
有时可以。换硬盘前我们会先从硬盘尝试数据恢复，能否成功取决于故障类型。

### 你们装海康、大华系统吗？
装。我们熟悉 Hikvision、Dahua、Ezviz、Tuya 等常见系统。

### 为什么实时画面正常却不录像？
摄像头没问题，故障在录像侧——通常是硬盘、录像计划或保留设置。技术人员一次上门就能定位。

### 监控系统该保存多久录像？
视硬盘容量、摄像头数量与分辨率而定，多数家庭保存两周到一个月不等。保留天数太短，常是「老录像不见」的原因。

### 怎么知道硬盘快坏了？
录像机通常会报硬盘错误、回放缺失或发出蜂鸣。技术人员可跑硬盘健康检测来确认。
