# Remot Autogate Tidak Berfungsi? Semakan dan Baiki

**Soalan:** Mengapa remot autogate saya tidak membuka atau menutup pagar?

**Jawapan:** Punca paling biasa ialah bateri remot lemah atau remot perlu diprogram semula. Jika butang dinding berfungsi tetapi remot tidak, isunya biasanya remot, bateri, antena atau penerima. Jika remot dan butang dinding kedua-duanya tidak berfungsi, papan kawalan, motor, bekalan kuasa atau sensor keselamatan mungkin perlu dibaiki.

## Mula dengan Semakan Ini

| Tanda | Punca biasa | Tindakan |
|---|---|---|
| LED remot malap/mati | Bateri remot lemah | Tukar bateri |
| Berfungsi dekat tetapi tidak jauh | Isu antena/jarak | Periksa kedudukan antena |
| Satu remot gagal, satu lagi OK | Remot rosak | Program semula atau ganti |
| Tiada remot berfungsi tetapi butang dinding OK | Isu penerima/antena | Periksa penerima dan pendawaian |
| Tiada apa berfungsi | Kerosakan kuasa/papan/motor | Periksa pemutus dan hubungi juruteknik |
| Pagar mula kemudian undur | Halangan atau sensor | Bersih landasan dan periksa sensor |

## Tukar Bateri Remot

Guna jenis bateri betul, biasanya sel litium kecil. Selepas menukar, uji dari jarak biasa dan dekat dengan panel kawalan. Jika remot terjatuh atau basah, butang atau sesentuh dalaman mungkin rosak.

## Pemrograman Semula

Sesetengah remot hilang kod selepas tukar bateri, lonjakan kuasa atau reset papan kawalan. Remot ganti baharu juga perlu dipelajari oleh penerima. Simpan semua remot sedia ada semasa menambah yang baharu, kerana sesetengah sistem memadam memori sebelum belajar semula.

## Masalah Jarak dan Antena

Jika remot hanya berfungsi sangat dekat:

- Pastikan antena penerima tegak dan tidak terperangkap dalam logam.
- Tukar bateri remot.
- Periksa struktur logam, kenderaan atau peranti baharu berhampiran penerima.
- Elak menekan butang berulang dari jauh; ia boleh menyahsebarkan sesetengah sistem.

## Bila Motor atau Papan Terlibat

Jika suis dinding juga gagal, periksa:

- Bekalan kuasa utama dan MCB/pemutus.
- Sama ada motor autogate berdengung tetapi tidak bergerak.
- Sama ada pagar terhalang atau terkeluar landasan.
- Sama ada pelepasan manual sedang digunakan.
- Sama ada baru ada lonjakan kilat atau banjir.

Jangan paksa pagar buka/tutup jika motor terkunci; guna pelepasan manual mengikut kaedah pengeluar.

## Harga Diterbitkan

## Soalan Lazim

### Mengapa remot saya hanya kadang-kadang berfungsi?
Selalunya isu bateri, jarak atau antena penerima. Gangguan logam atau elektronik berdekatan juga boleh mengurangkan kebolehpercayaan.

### Boleh saya beli remot autogate universal?
Sesetengah sistem boleh menerima remot serasi, tetapi frekuensi dan pengekodan mesti sepadan. Penerima mungkin perlu diprogram semula.

### Bagaimana jika pagar buka tetapi tidak tutup?
Periksa halangan, sensor keselamatan dan tetapan had tutup. Jika ia mengundur tanpa sebab jelas, juruteknik perlu memeriksa papan dan sensor.
